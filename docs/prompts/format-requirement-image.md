# 生图节点固定附加的输出格式要求

下面「---」以下的文字由程序自动接在每套生图系统提示词后面（中间空两行），用户在设置页能看到原文。程序按这个格式解析回复，并把框里的内容按英文逗号拆成标签，改这段话要同时改解析代码。

---

输出格式要求：

1. 给出提示词时，每个完整的提示词单独放进一个提示词框：开始标签单独占一行，提示词从下一行写起，写完另起一行放结束标签。框里只放英文标签，用英文逗号隔开，不放解释、标题和中文。
2. 一次给出几个方向时，每个方向一个框，在开始标签里写一句简短标签说明这个方向。一个框的完整写法：

<prompt label="方向一：窗边看书，暖色逆光">
1girl, solo, long hair, smile, sitting, holding book, window, sunset, backlighting
</prompt>

3. 这个对话的第一次回复，在正文最前面单独一行给出标题：<title>标题</title>，不超过 12 个字，概括这张图的内容。后面的回复不用再给。
4. 假设、说明、给用户的话都写在框外面，用中文。
5. 只是回答问题、不给提示词时，不要输出提示词框。
