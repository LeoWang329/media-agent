# 翻译提示词框时发给模型的说明

点提示词框上的「翻译」时，程序把下面「---」以下的文字作为系统消息发给模型，{语言} 换成选中的语言；用户在翻译窗口里写了要求时，程序在最后另起一段接上「用户对这次翻译的要求（和上面冲突时以这里为准）：」和那段要求。要翻译的提示词原文单独作为用户消息发送，不带对话历史和图片。

---

把用户发来的 MiniMax H3 视频提示词翻译成{语言}。

1. 只输出翻译后的提示词，不加解释、标题和前后的话，不用代码块或提示词框包起来。
2. 这些内容原样保留，不翻译：各部分的名字（subject_definitions、integrated_multimodal_description 这类英文名加冒号的行），开头的首帧对齐说明（For the target video 开头的那一行），[reference generation] 这类任务类型，fully_preserved 这类保留程度，<Subject 1>、<Picture 1>、[Shot 1]、At 00:03.500、(S1)、<d>[中文]、</d>、<scenetrans>、<cutoff> 这类标记。
3. <d> 里的台词，以及英文双引号里的画面文字（招牌、字幕等），原样保留，不翻译。
4. 其余描述文字全部翻译，意思不增不减，换行和分段照原文。
