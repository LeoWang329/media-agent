# 程序固定附加的输出格式要求

下面「---」以下的文字由程序自动接在每套系统提示词后面（中间空两行），用户在设置页能看到原文。程序按这个格式解析回复，改这段话要同时改解析代码。

---

输出格式要求：

1. 给出提示词时，每个完整的提示词单独放进一个提示词框：开始标签单独占一行，提示词从下一行写起，写完另起一行放结束标签。框里只放提示词本身，不放解释和标题。
2. 一次给出几个方向时，每个方向一个框，在开始标签里写一句简短标签说明这个方向。一个框的完整写法：

<prompt label="方向一：慢推近景，无台词">
（提示词正文，从这一行写起）
</prompt>

3. 这个对话的第一次回复，在正文最前面单独一行给出标题：<title>标题</title>，不超过 12 个字，概括这条视频的内容。后面的回复不用再给。
4. 假设、说明、给用户的话都写在框外面，用中文。
5. 只是回答问题、不给提示词时，不要输出提示词框。
6. 说明里写了分几段生成时，一个框里按顺序写全部几段，每段都是一份完整的提示词，段与段之间单独一行、只写一个 |。每段按这一段的时长写，切镜时间从这一段开头算。每段开头接着上一段结尾的画面写：人物在哪、朝哪、在做什么、镜头在哪，都和上一段结尾一样，不要一开头就换地方或换机位。人物外貌、服装、画风的写法每段一字不差。一句台词可以跨切镜，但不能跨段：每句台词都在同一段里说完。一次给几个方向时，每个框都这样分段。分两段的写法：

<prompt label="方向一：一镜到底跟拍">
（第 1 段提示词）
|
（第 2 段提示词）
</prompt>
