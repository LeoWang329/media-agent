# 提示词画布 · 生图功能交接（给设计）

给做界面设计的 agent 看。程序已经照你上次的原型做好了（原型在 `web/prototype/`），这次在上面加两样东西：全局的思考开关，和生图。这份讲新功能做什么、有哪些规则、要显示什么信息、用户要完成什么事。

这次不是从零设计。新东西放进现有的页面里，沿用现有原型的颜色、字体、组件、暗色亮色两套主题和剪辑台的方向（`web/prototype/review/design-direction.md`），不另起一套。新东西放在哪、怎么操作、长什么样，由你定。

规则的细节在 `docs/dev-plan.md` 的 5.12 到 5.21 节；为什么这么定，在 `docs/requirements-interview-image.md`。两份和这份说法不一样时，以那两份为准，并在说明里指出来。

## 1. 这次加的东西，给谁用

- 还是那一个人，同一台 Windows 电脑，Chrome 或 Edge，桌面显示器。
- 新用途是画动漫风格的图。出图用的主模型叫底模，分 IL（Illustrious）和 Pony 两个系列，都吃 Danbooru 标签：提示词不是一段话，而是一串英文短标签，比如 `1girl, solo, long hair, blonde hair, smile`。
- 他不熟英文标签，靠中文：用中文和 AI 聊，让 AI 写标签；自己改的时候用中文搜标签；每个标签下面要看到中文。
- 出图的程序叫 ComfyUI，不在这台电脑上（这台只有核显）。一台是局域网里有显卡的电脑；另一台是在 AutoDL Art 上租的云显卡机器，开着就按秒扣钱，不用时要关机。
- 出的图大多用不上。挑出好的「下载」进资产库，其中一些再拿去当视频节点的参考图。
- 核心诉求还是反复试：改几个标签、换个种子、一次出四张、挑一张放大修脸、回头比较之前那组。

## 2. 新名词

请沿用这套叫法。

| 词 | 意思 |
| --- | --- |
| 生图节点 | 画布上用来写生图提示词、出图的节点。和视频节点一样是一段对话，区别是选的系统提示词是生图用的。一张画布上两种节点会混在一起。 |
| 标签 | Danbooru 的一个标准写法，英文短词，比如 `long hair`（长发）。一条生图提示词就是一串标签，用逗号隔开，越靠前影响越大。 |
| 词库 | 本机存的 12 万个标签，每个有中文名、使用次数、分类。用来中文搜标签、给标签配中文、查出写错的标签。 |
| 分类 | 标签分五类：通用（外观、动作、背景这些）、角色、作品、画师、元标签（图片本身的属性，比如高分辨率）。 |
| 权重 | 加强或减弱某个标签，写成 `(blonde hair:1.2)`，1 是正常。 |
| 别名 | 一个标签的旧写法或另一种写法，比如 `blond hair` 是 `blonde hair` 的别名。程序自动换成标准写法。 |
| 不认识的标签 | 词库里没有的写法，可能是 AI 编的，也可能是有意写的（比如某个 LoRA 要的触发词）。标出来，给几个最接近的让他挑，不自动删。 |
| 底模、系列 | 出图用的主模型文件，分 IL 和 Pony 两个系列。两个系列开头要加的质量词、默认负面词不一样，程序按系列自动加。 |
| LoRA | 挂在底模上的小模型，用来固定某个角色或画风，带一个强度。 |
| 负面词 | 不想在图里出现的东西，比如 `watermark`。每个系列有一套默认的。 |
| ComfyUI | 出图的程序，跑在有显卡的电脑上。 |
| AutoDL 实例 | 云上租的有显卡的机器，上面跑着 ComfyUI。要开机才能用，开机要等一会儿；开着就扣钱，每小时一两块到几块。 |
| 工作流 | 出图的步骤。程序自带一套基础的；他也能导入自己在 ComfyUI 里搭好的。 |
| 出一组 | 点一次「生图」，出 1 到 8 张，ComfyUI 一张一张出。 |
| 种子 | 一个数字，决定出图的随机性。种子和其他参数都一样，出的图就一样。 |
| 临时文件夹 | 出的图先放在这里。程序不自动删，他自己看着清。 |
| 下载 | 把出的图存进他选的文件夹，一般是资产库里的。下载过的才能当视频的参考图。 |
| 片段 | 一小串常用标签，比如某个角色的外观，起名字存起来，写提示词时插进去。 |
| 放大、修脸 | 对一张出的图再加工：放大到 1.5 倍或 2 倍并补细节；把脸重画清楚。 |
| 参考图生图 | 拿一张图做参考出图，有三种：照着整张图改（图生图）、照着图里人的姿势画、照着图的画风画。 |
| 反推 | 让 ComfyUI 看一张图，写出它的标签。 |
| 思考 | 有的 AI 回答前会先想一会儿，想得越深越慢、越贵。这次加一个总开关控制想不想、想多深。 |

## 3. 一次典型的使用

1. 新建一个节点，系统提示词选「il」（IL 系列的生图提示词）。面板上原来的视频时长和比例，换成了图的尺寸和张数。
2. 用中文写：「初音未来坐在窗边看书，傍晚，暖色」。AI 回了三个方向，每个方向一串标签，每个标签下面有中文。有一个标签 AI 写的是别名，程序换成了标准写法并注明；有一个词库里没有，标了出来。
3. 他点开那个不认识的标签，从候选里挑了一个换上。又打开标签编辑窗：打「双马尾」加了一个标签，把「微笑」的权重调到 1.2，插了一个之前存的片段「我的画风」，存成新版本。
4. 点「生图」，用局域网那台出 4 张。框下面先显示排队，再显示进度，图一张张出来。
5. 第 3 张不错：点开看大图和参数，点「只换种子再来」又出了一组；挑其中一张放大，再修脸。
6. 把满意的两张下载到资产库的「角色设定」文件夹。
7. 回到一个视频节点，把这张图放进槽位当参考图，写视频提示词。
8. 晚上换用 AutoDL：点生图时实例还关着，程序自动开机，等了一分多钟开好才出图；出完空闲 15 分钟，自动关机。

## 4. 功能和规则

### 4.1 思考

- 设置里一个总档位：关、低、中、高。写提示词、翻译、转标签三个用途，各自可以跟总开关，或单独选一档。默认写提示词跟总开关，翻译和转标签是关。
- 每套模型配置要选这家「开思考的写法」，有五种，不支持思考的选「不支持」。靠换模型名开思考的（比如 DeepSeek），还要填一个开思考用的模型名。
- 回复的时候：AI 在想，正文还没出来，要显示「正在思考 12 秒」，不然看着像卡住了。想完了，有的模型会把想的内容发回来（DeepSeek、通义），折叠在回复上面，写着「思考了 38 秒」，点开能看全文，可能几千字；不发回来的只显示想了多久。
- 想的部分也算钱，现在的花费显示照常算进去。

### 4.2 生图节点

- 选了生图用的系统提示词，节点就是生图节点；换回视频的提示词就变回去，已有的对话不动。
- 自带两套生图提示词：il 和 pony。他也能复制一份来改。设置里的系统提示词列表要看得出哪套是生图用的、属于哪个系列。
- 和视频节点比，面板上变的地方：
  - 视频时长和比例换成尺寸和张数。尺寸九档：一档正方形，四档竖的，四档横的，比如 832×1216。张数 1 到 8，默认 4。
  - 多一组出图设置：用哪台 ComfyUI、工作流（自带的或导入的）、底模（只列这个系列的）、LoRA（可以几个，各带强度）、步数、CFG（提示词管得多严）、采样器、调度器、种子（每次随机，或固定一个数）、评级（不加、全年龄、擦边、成人）、额外的负面词。每个节点各存一份，新节点按系列的默认值填。常动的是尺寸、张数、底模、LoRA、种子，其余很少动。
  - 选了导入的工作流，底模、LoRA、步数这些由工作流自己定，不用显示。
  - 槽位还在：图照样给 AI 看，AI 能照着图写标签；也是参考图生图的来源。
- 提示词框上的按钮：复制、生图、打星、编辑、沿这个方向继续。没有翻译和上传清单。
- 画布上的节点卡片：出过图的，缩略图位置显示最近出的几张；没出过的照旧显示槽位里的图。时长和比例那一行换成尺寸和系列。

### 4.3 提示词框里的标签

- 框里是一串标签，每个标签显示成一个小块，英文在上，中文在下。按使用次数算，97% 的标签有中文；画师名大多没有中文，只显示原名。
- 权重不是 1 的要看得出来，比如标着 1.2。
- 最好看得出分类，扫一眼就能找到角色名、作品名。
- 别名：程序已经换成标准写法，小块上注明「原来写的是 blond hair」。
- 不认识的：标出来，但它不是错误，可能是有意写的。点开看最接近的几个候选（英文、中文、使用次数），点一个就换掉，存成新版本。
- 一个框常见 20 到 40 个标签，多的 60 个；一次回复可能有 3 个方向、3 个框。要能一眼读下来，一个标签不能占一大块地方。
- 复制拿到的是一行英文，比如 `long hair, (blonde hair:1.2), hatsune miku`。

### 4.4 标签编辑窗（手动改生图提示词）

- 点框上的「编辑」打开。框里的标签都变成能操作的小块。做法和现在输入框里 @ 选图的小块一样：小块和打的字在同一行文字里。
- 打字联想，中文英文都行。比如打「金发」，弹出「blonde hair · 金发 · 通用 · 219 万」。每个候选显示英文、中文、分类、使用次数，使用次数让他知道这个标签常不常用；靠别名对上的注明是哪个别名。上下键选、回车加；打逗号，前面打的字也变成一个小块。词库里没有的英文也能加，标「不认识」。
- 小块能拖动调顺序、删掉，点一下调权重（0.1 到 2.0，每次 0.1）。
- 打的中文搜不到（比如一整句「坐在窗边看书」）：给一个「让 AI 转成标签」，转回来的几个标签变成小块插进来，要等几秒。
- 插片段：搜片段名插进来，插进来就是普通小块。
- 选几个小块「存成片段」：起名字，选分类。
- 从图反推：选一张图（槽位里的，或这个节点出过的），ComfyUI 看图写出标签，加在末尾。要等几秒到十几秒，ComfyUI 得连得上。
- 存：存成这条回复的新版本（和现在手动改提示词一样，能切版本），不问 AI。也能放弃不存。

### 4.5 出图

- 点框上的「生图」，按节点的出图设置出一组。也能选参考图的方式：不用参考图（默认）、图生图、姿势参考、画风参考。后三种要从槽位里选一张图，各有一个强度。
- 一组挂在这个框下面，按时间排，一个框可以有很多组。每张图有自己的状态：
  - 排队：排在第几。ComfyUI 一次只出一张，别人也可能在用它。
  - 正在出：第几步、共几步。一张几秒到几十秒，看显卡。
  - 出完：显示图。
  - 失败：说原因，比如连不上、底模文件不在、显存不够、缺插件。
  - 已叫停。
- 一组没出完时能叫停，出完的留着。
- AutoDL 实例关着时点生图：先开机，显示「正在开机，等了 45 秒」，开好了再排队。开机可能要一两分钟。
- 点一张图看大图和参数：正面提示词（含程序加的固定开头）、负面词、种子、底模、LoRA、尺寸、步数、CFG、采样器、工作流、用的哪台 ComfyUI、出这张用了多久；放大或修脸出来的，写着从哪张来。能做的事：下载、打星（这张好）、删除、在资源管理器里显示、同样参数再来（同一个种子）、只换种子再来、放大（1.5 倍或 2 倍）、修脸。
- 图是 1024 像素上下的 PNG，一张 1 到 3 MB。一组默认 4 张，一个框可能挂几十张。

### 4.6 临时文件夹和下载

- 出的图先放在工作文件夹里的临时文件夹，按日期分子文件夹。程序不自动删，他自己在资源管理器里清。
- 设置里看得到临时文件夹在哪，能一下在资源管理器里打开。
- 下载：选一个文件夹（记住上次选的），把图存过去；那个文件夹不在资产库里，问要不要导入。能多选几张一起下。下载过的图要看得出「已下载」。
- 他清掉临时文件夹以后，节点里那些图没了：下载过的改显示下载的那份；没下载过的显示「已清理」，参数还在，照样能「同样参数再来」。
- 视频节点的槽位只能从资产库选图，所以出的图要先下载，才能当视频的参考图。

### 4.7 ComfyUI 和 AutoDL

- 两台 ComfyUI：局域网那台（填地址）和 AutoDL 实例（填开发者 Token、选实例）。出图用哪台随时能切，所有节点共用。
- 随时看得到：现在用哪台、连不连得上；AutoDL 的状态（已关机、开机中等了多少秒、运行中）和还有多久自动关机。AutoDL 开着就扣钱，他要放心不用的时候一定是关着的。
- 能手动开机、关机。空闲多少分钟自动关机在设置里改，默认 15 分钟。
- 程序关掉以后就管不了实例了，所以实例开着的时候，界面上要明显。
- 底模、LoRA、采样器这些选项是从那台 ComfyUI 读来的，两台装的可能不一样，能刷新。
- 每个底模要标属于哪个系列：程序按文件名猜，他在设置里改。

### 4.8 工作流

- 自带的基础流程不用管。
- 导入：他在 ComfyUI 里用「导出（API）」存下来的 JSON 文件。程序自动认出往哪填提示词、种子、尺寸；认不出或者有几个候选时，列出工作流里的节点让他选。导错了格式（普通的工作流文件），告诉他怎么导出。
- 用导入的工作流之前，程序会查那台 ComfyUI 装没装工作流要用的插件，缺了就说缺哪个。
- 设置里管理导入的工作流：改名、重新指定往哪填、删除。

### 4.9 片段库

- 一个片段：名字、分类（角色、画风、质量词、其他）、一串标签。
- 在标签编辑窗里存和插（4.4）。
- 设置里看全部片段，按分类分组，能改名、改分类、改内容、删除。片段有几个到几十个。

### 4.10 首页

- 最近动过的节点：生图节点显示最近出的图。
- 打过星的提示词：生图的框显示标签（带中文）和它出过的几张图，打过星的图在前；能复制、能「再出图」，用那个节点现在的设置再出一组，出的图挂回那个节点。

### 4.11 设置

新加的几块：

- 思考：总档位和三个用途。模型配置里加「开思考的写法」和「开思考用的模型名」。
- ComfyUI：局域网的地址和测试连接（显示 ComfyUI 版本、显卡、显存）；AutoDL 的 Token、选实例、开机关机、空闲多久自动关机。
- 底模和默认值：读到的底模各属哪个系列；IL、Pony 各一套默认值（固定开头、默认负面词、评级词的写法、步数、CFG、采样器、调度器、clip skip），以及放大、姿势、画风默认用哪个模型、反推用哪个模型。这些他很少改，但要能改，每项有一句说明。
- 工作流（4.8）。
- 词库：哪天的、多少个标签、多少个有中文；「更新词库」，大约要 4 分钟，要显示下到哪一步。
- 片段库（4.9）。
- 出的图：临时文件夹在哪，在资源管理器里打开。

### 4.12 等待和出错

这些状态他会经常碰到，都要有交代：

- AI 在思考，正文还没出来。
- 词库在更新，大约 4 分钟。
- 让 AI 转标签、反推，几秒到十几秒。
- AutoDL 开机中（一两分钟）；开机失败：Token 不对、余额不够、等太久。
- ComfyUI 连不上、底模文件不在、显存不够、缺插件或缺模型（说清缺哪个、要装什么）。
- 出图排队、进行中、叫停、失败。
- 临时文件被清掉的图。
- 导入的工作流格式不对、认不出往哪填。

## 5. 数据规模

- 词库：12 万个标签；联想时最多显示 20 个候选。
- 一个框：20 到 40 个标签，多的 60 个。
- 一组：1 到 8 张，默认 4；一个框可能有十几组。
- 一张图：1024×1024 上下的 PNG，1 到 3 MB；放大后 2048 上下。
- 出一张：几秒到几十秒；AutoDL 开机一两分钟。
- 片段：几个到几十个。导入的工作流：几个。
- 思考原文：几百到几千字。

---

## 6. 每样东西要能看出什么

不是要求怎么显示，是说这些信息他需要，缺了会出问题。

- **生图节点的卡片**：标题、是生图节点、哪个系列、最近出的图、有没有打星、正在出图（几张、进度）、有没有失败。
- **一个标签**：英文、中文、权重、分类；是不是从别名换过来的；是不是不认识。
- **一组出图**：什么时候出的、几张、用的哪台、每张的状态（排第几、进度、失败原因、已叫停）；是普通出图，还是放大、修脸、哪种参考图。
- **一张出的图**：图、种子、下载过没有、打星没有、被清理没有。
- **大图的参数**：4.5 列的那些。
- **AutoDL**：开没开、开了多久、多久后自动关。
- **一条开了思考的回复**：想了多久，思考原文。
- **标签候选**：英文、中文、分类、使用次数，靠别名对上的注明。

## 7. 运行环境和限制

- 和上次一样：本机网页，只监听本机，一个人用，全中文，Windows 上的 Chrome 或 Edge，桌面显示器。手机布局沿用现有原型的做法，新功能不用专门做手机版。
- ComfyUI 在别的机器上，图要从网络取回来，出图慢；AutoDL 按开机时间收钱。
- 工作文件夹在同步盘上，两台电脑轮流用：片段库、导入的工作流、词库、出的图两台都看得到；AutoDL 的 Token、出图用哪台 ComfyUI，每台电脑各自设。

## 8. 要交的东西

- 在现有原型上改：
  - `canvas.html`：生图节点、标签小块、标签编辑窗、出图和大图、ComfyUI 和 AutoDL 的状态、思考；
  - `home.html`：生图节点的卡片、打过星的生图框；
  - `settings.html`：新加的几块。

  现有的视频节点功能不能改坏，视频节点和生图节点要能同时出现在一张画布上。
- 和上次一样，右下角的「原型」切换框能切到 4.12 列的各种状态。
- 截图放 `web/prototype/review/`：1440×900 暗色、亮色，1366×768 亮色。
- 一份说明，像 `review/home-notes.md` 那样：怎么看、为什么这么排、原型里的假数据和限制、建议加的功能（没画进去的）。
- 标签的假数据用真实的 Danbooru 标签和中文，从 `data/danbooru/` 里挑：`zh/general.csv`、`zh/character.csv` 这些文件，列是 `tag, category, aliases, zh, count, notes`。
