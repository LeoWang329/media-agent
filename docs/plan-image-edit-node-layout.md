## 2. ⑥「功能」是个下拉菜单（第一行）

一排按钮放不下（以后还要加扩图、高清放大、深度迁移），而且每个功能的说明得跟着走。所以做成下拉，**并且放到最上面**——点开编辑节点，第一个看到的就是「要干什么」：

```
│ 功能  ┌──────────────────────────────────┐
│       │ 指令编辑                       ▾ │  ← 收起来时只显示当前这个
│       └──────────────────────────────────┘
│         点开（菜单往上探出去，盖住消息区）：
│       ┌──────────────────────────────────┐
│       │ ✓ 指令编辑                        │  一句话改图：放一张图 + 写一句要改什么，改哪儿模型自己找
│       │   转真人                          │  动漫 / 插画 → 真人照片，构图长相照原图
│       │   换装                            │  只换衣服，长相和姿势不动
│       │   局部重绘                        │  指定一块区域重绘：拖框或涂抹，别处一个像素不动
│       ├──────────────────────────────────┤
│       │ 以后往这里加：扩图、高清放大、深度迁移 │
│       └──────────────────────────────────┘
│         要 1 张：① 要改的图
│         一句话改图：放一张图 + 写一句要改什么，改哪儿模型自己找
```

- 每一项**右边跟一句说明**；选完，下面那两行（要几张 / 干什么的）一起换。
- 菜单**往上弹**，盖在消息区上——面板本身不因为菜单变高。选完自己收起来，点别处、按 Esc 也收。
- **换功能不动你已经选的图和写好的字**；字段区、提示词菜单跟着换。

## 3. ⑨「提示词」下拉：每个功能一套现成的（转真人除外）

你说「我也可以选择对应的那些提示词」，就是这一行。选中一条 → 填进 ⑩ 那行 → **那行照样能改**。

```
│ 提示词 [ 换衣服                    ▾ ]
│        [ Change her coat into a black studded leather biker jacket ]
│                                  ↑ 选完填这里，可以直接改
```

**指令编辑**：换衣服 / 换背景·换天气 / 加一个东西 / 去掉一个东西 / 改光线·色调 / 改表情·姿势 / 自己写

**换装**：换外套 / 换整套 / 加配饰 / 去配饰 / 自己写

**局部重绘**：换衣领 / 修手 / 去掉杂物 / 补细节 / 自己写

**转真人：没有这个下拉**——它的提示词是定死的，没得选（那一行显示"定死的，没得选"，正文灰的、改不了）。

- 每条**右边跟一句说明**（"保持脸和背景""框住领子"这样），菜单宽度跟着面板走。
- 最后一条固定是「**自己写**」：不看预设，把 ⑩ 那行清空让你自己填。
- 这些是**起点不是枷锁**：模板给的是"能直接跑通的一句话"，你改完就是我们发出去的那句。
- 提示词清单放哪：跟功能定义放一起（`packages/shared` 里，和 `KREA2_EDIT_PRESETS` 一个地方），以后加一条就是加一行。

## 4. 四个功能各自的参数区（都只要一张图）

### 4.1 指令编辑（1 张）

```
│ 功能   [ 指令编辑 ▾ ]
│        要 1 张：① 要改的图
│        一句话改图：放一张图 + 写一句要改什么，改哪儿模型自己找
│ 图     ① ② ③ ＋
│ 提示词 [ 换衣服 ▾ ]
│        [ Change her coat into a black studded leather biker jacket ]
│ 相似度 [ 1.0 ]                                        [ 开始 ]
```
- 走 Krea2 编辑档（T07 那套）。**T07 本身支持双图（场景 + 主体），这一版不用**——见第 8 节。

### 4.2 转真人（1 张）—— 走 [转真人用法](krea2-real-usage.md) 那套（作者原件 `krea2_v10.json`）

```
│ 功能   [ 转真人 ▾ ]
│        要 1–2 张：① 要转的动漫图 ② 真人参考图（只有「换脸」用得上）
│        动漫 / 插画转真人照片：构图、姿势、长相都照原图，只把画风变成真人
│ 图     ① ② ③ ＋      ← 「只转真人」时 ② 是暗的、不算数
│        要转的 真人参考
│ 提示词 ( • ) 让模型看图写     ( ) 我自己写     ← 就是工作流里那个「① 用反推吗」
│        [ transform the image to realistic photograph ]   ← 反推时灰的（跑的时候模型现写）
│        ⚠ 主触发词必须放最前面，一个字都别改
│ 辅助词 [looking at camera] [Film filter] [hazy] [photorealistic, highly detailed] …
│        ← 只有「我自己写」时给；点一下就接进上面那行
│ 做法   ( 只转真人 ) ( 换脸 · 用图 2 的长相 )   ← 就是工作流里那个「② 双图吗」
│        要两张 —— 图 2 是「换成谁的脸」，不给就退回只转真人
│ 图 2 强度 [ 1.0 ]    ← 只有「换脸」才显示；「像图 2 多少」的连续旋钮
│ LoRA   转真人 [ Krea2_Anything2RealCharacters-V3 ▾ ] 强度 [ 1.0 ]
│        人物 ① [ 不加 ▾ ] 强度 [ 0.6 ]      [ ＋ 再加一个 ]
│ 版本   [ 作者原版（保真更好） ▾ ]                        [ 开始 ]
│        出图尺寸跟着图 1 走（长边 1536、16 的倍数）—— 这里不用填。
│        步数 8 / CFG 1 / euler / beta57 都固定。
```

**「谁写词」是个开关，两种模式互斥**（跟工作流里的接线一一对应）：

| | 提示词那行 | 辅助词 | 机器上发生什么 |
| --- | --- | --- | --- |
| **让模型看图写（反推）** | 灰的，跑完把模型写的那句显示在这里 | 不给（反推写什么就是什么） | 图里挂上 `llama_cpp_*` 那条链：35B MoE 去审查 VLM 看图画词，输出直接接到 `Easy_QwenEdit2509.prompt` |
| **我自己写** | 可改，预填主触发词 | 给一排作者训练时带的词 | 图里**根本不生成**反推链（省时间省显存） |

- 反推开着比关掉多花 ~9 秒；跑完**反推模型常驻约 5GB**（`force_offload = false`，照调研）——**就这样，5 个 G 不值得每次为它重新加载**。
- 反推要额外的插件 + 两个大模型文件（gguf + mmproj），缺了就在界面上说清装哪个（照"缺插件"那套）。

**「做法」是另一个开关**（工作流里的「② 双图吗」）：

| 做法 | 要几张 | 提示词 | 图 2 强度 | 机器上 |
| --- | --- | --- | --- | --- |
| 只转真人 | **1 张**（图 2 变暗、不参与） | `transform the image to realistic photograph` | 不显示 | 图 2 那条链不生成 |
| 换脸 · 用图 2 的长相 | **2 张** | 上面那句 **+** `, with the character looking exactly like the one in Figure 2.` | 显示（0–10） | 多接 `LoadImage → ColorCorrect → 缩放 → image2` |

⚠️ **图 2 带过来的是「整颗头」，不是只换脸**：发色、发型、帽子、耳环全跟过来，提示词里明写 `silver hair` 也压不住 —— 这是这条路固有的，不是 bug。**想要"脸有点像、发型还是自己的"，把「图 2 强度」调到 0.3–0.6**（实测 1.0 全盘接管、0.6 混合、0.0 也压不干净）。**要"只换脸"得靠换脸节点（像素级贴脸），那是另一条路。**

**LoRA 是两组，都能调**：

- **转真人 LoRA**：默认就是 `Krea2_Anything2RealCharacters-V3`、强度 1（作者建议 0.8–1.0），**但可以换 / 可以调**。
- **人物 LoRA**：默认「不加」，可以**挂好几个**（`Lora Loader Stack` 有 6 槽），每个带自己的强度，默认 0.6。
- ⚠️ 两条注意：**只能挂 Krea2 家族**（SDXL / Illustrious / Pony 的挂上去完全不生效）；这个 stack 的 **clip 输出也接到了 `Easy_QwenEdit2509`**，所以 LoRA 同时作用于模型和文字理解，而且**会跟参考图抢** —— 两个都开时总强度别顶满，容易花图。
- **想指定某个具体的人，图 2（配「图 2 强度」）比 LoRA 直接得多**，LoRA 是次要手段。

**消息区也跟着换**（这是"不堆一起"的关键）：转真人没有"跟模型聊两句"这回事——反推是**跑图的时候在 ComfyUI 里跑的**，不是我们这边聊天。所以上面那堆候选框**整块换成说明卡**：

```
│ ┌ 转真人的提示词不用你写 ────────────────────────────────────────┐
│ │ 选「让模型看图写」，跑图的时候工作流里的反推模型会先看图，       │
│ │ 把主体 / 长相 / 服装 / 构图 / 环境 / 光 / 材质逐项写成英文，     │
│ │ 写完接上固定触发词，直接喂给生成模型。跑完那句话显示在下面。     │
│ │ 想自己掌控就切到「我自己写」。                                  │
│ └────────────────────────────────────────────────────────────────┘
│ ┌ 这条不吃通用质量词 ────────────────────────────────────────────┐
│ │ 别加 8k / DSLR / masterpiece / best quality，会跟触发词打架。    │
│ └────────────────────────────────────────────────────────────────┘
```

- 底部「跟模型说」那一整条**收起来**——这个功能用不上它。

**这一块和别的功能不一样的地方（照调研文档抄，界面上要写出来）**：

- **主触发词**（`transform the image to realistic photograph`）**必须放最前面、一个字都别改**。
- **出图尺寸不由我们填**，跟着那张图缩放后的尺寸走。
- **步数 / CFG / 采样器 / 调度器**固定 8 / 1 / `euler` / **`beta57`**，不给你改（调研文档：照抄别动）。
- **别加** `8k` / `DSLR` / `masterpiece` / `best quality` 这类通用质量词。
- **人物 LoRA**（`Lora Loader Stack` 第 2 槽往后）：只能挂 Krea2 家族的，默认不加、强度先 0.6；它**同时喂 CLIP**，而且**会跟参考图抢**——两个 LoRA 总强度别顶满，容易花。
- 「版本」选「无审查」时底模和文字理解各换一个（见调研文档第 7 节），接线不变。
