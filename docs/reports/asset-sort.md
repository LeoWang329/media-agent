# 资产库排序报告

资产库能排序了。规则在 `docs/dev-plan.md` 6.3「排序」，为什么这么定见 `docs/requirements-interview.md` 文末「补访谈：资产库排序」。

## 做了什么

- 资产库网格上方、张数右边多了一个下拉，四种排法：修改时间新的在前、修改时间旧的在前、文件名 A 到 Z、文件名 Z 到 A。默认新的在前。
- 修改时间一样的按文件名排。按文件名排时不分大小写，名字里的数字按大小比（b2 在 b10 前面），和原来一样。
- 选过的排法记在这台电脑的浏览器里，下次打开资产库照上次的。
- 搜索结果、「@」选图那排、拼图窗口里选图那栏都跟着选的排法。
- 换排法时网格回到最上面。

## 怎么做的

- 文件夹里的图，服务端原来就一次全给，浏览器拿到后自己排。换排法直接重排，不用再读一遍硬盘。
- 搜索最多给 200 条，排法不同，取到的 200 条也不同，所以搜索时把排法带给服务端，服务端排好再取。按修改时间排时要先查到每个搜到的文件的修改时间，搜到的很多时比按文件名排慢一点，最多和打开导入的那一层文件夹时查的一样多。
- 搜索接口多了一个 `sort` 参数，不带是按文件名，带错了返回 400。
