# P8 思考 报告

## 做了什么

有的模型回答前会先想一会儿。这一阶段让程序能管想不想、想多深，并把想的过程显示出来。规则在 `docs/dev-plan.md` 5.12。

- **设置里多了「思考」一节**：
  - 一个总档位：关、低、中、高。
  - 三个用途各自选「跟总开关」或者某一档：写提示词、翻译、转标签。默认写提示词跟总开关，翻译和转标签是关。
  - 存在工作文件夹的 `settings.json`，两台电脑共用。
  - 下面列出每套模型配置开思考的写法、各档位实际发什么，点「改」跳到模型配置里的那一套。
- **模型配置多了两项**，首次设置和设置页都有：
  - 「开思考的写法」：不支持、reasoning_effort、enable_thinking、thinking.type、换模型名。
  - 选「换模型名」时多一项「开思考用的模型名」。
- **发请求时带参数**：按写法把档位换成那家接口认的参数。写提示词和翻译各按自己的档位；转标签的请求在 P9 做，到时按「转标签」那一档。
- **读思考原文**：回复里的 `reasoning_content`（DeepSeek、通义）和 `reasoning`（有的转发平台用这个名字）都读。思考原文边收边存进回复，等了多久才出第一个正文字也记下。下一轮发给模型时不带思考原文。
- **显示**：
  - 开着思考时，正文出来之前回复里只有一行「正在思考 N 秒」，秒数每秒走。
  - 想完以后，收到过思考原文的回复上面多一块折叠着的「思考了 N 秒 · 多少字 · 不会带进下一轮对话」，点开看原文。没收到原文的只显示想了多久。
  - 对话面板顶上多一个按钮，显示写提示词现在思不思考、哪一档（「思考 中」「不思考」「不支持思考」），点一下去设置里的「思考」。
- **mock-llm**：照 9.1 补了思考。请求带了思考参数，就在正文最后一行写出收到的参数；参数表示开着思考时，正文前先分 4 段发思考原文，共 1 秒。

## 和计划不一样的地方

- **10.3 第 1 条最后一步改了说法**。原来写「译文里没有『思考参数』」，和 5.12 对不上：reasoning_effort 这种写法关的时候也发 `low`（多数家关不掉思考），mock 收到就会写出这一行。改成「译文最后一行的『思考参数』是 `low`」，测的还是同一件事：翻译用自己的档位（关），不跟总档位（中）。`docs/dev-plan.md` 已经改了。
- **设置里 reasoning_effort 那一行的说明**：原型写的是「低中高发 low / medium / high」，漏了关也发 low，改成「关和低发 low，中发 medium，高发 high」。
- **换模型名没填「开思考用的模型名」时**：原型那一行会显示「换成『』」，改成说还没填、低中高也用原来的模型名，程序本来就是这么发的。
- **手动改提示词生成的新版本不带思考原文和思考时间**：这一版没调模型，和不带 token 用量是一个道理。之前会照抄原来那条的，改了，5.12 里补了一句。

## 顺带发现的

深色主题下，所有下拉框右边的小箭头都不见了。原因是原型 `app.css` 里深色主题给下拉框设背景时用的是 `background` 整个覆盖，把画箭头的背景图也盖掉了。原型里也是这样，这次没动，要修改一行就行。

## 你要测的

11.3 第 1 条：用自己常用的几家模型配置打开思考，关低中高都试一遍；DeepSeek 或通义能看到思考原文；花费里算上了思考。

各家大概选哪种写法（以那家的接口文档为准）：DeepSeek 选「换模型名」，填 `deepseek-reasoner`；通义选 enable_thinking；豆包、智谱选 thinking.type；OpenAI、Gemini 这类选 reasoning_effort。
