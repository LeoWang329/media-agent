# P11 导入工作流和 AutoDL 报告

这一步分两半做，都做完了：前一半是导入工作流，后一半是 AutoDL 开机关机。

## 做了什么：导入工作流

规则在 `docs/dev-plan.md` 5.18。

- **设置「工作流」**：
  - 列出内置基础流程和导入的工作流。每个写着文件名、什么时候导入的、往哪四处填（正面、负面、种子、尺寸）。
  - 能改名、重新指定往哪填、删除。删除挪进工作文件夹的 `.trash`，用它的节点出图时换回内置流程。
  - 导入的存在工作文件夹 `workflows/<id>.json`，两台电脑共用。
- **导入**：点「导入工作流…」选一个 JSON。
  - 普通格式的（顶层有 `nodes`、`links`）：说清楚要在 ComfyUI 里用「导出（API）」再存一份，附上步骤。
  - 四处都认出来的：直接列出来，起个名字就能导。
  - 认不准、有几个候选的：列出工作流里能填的节点让你挑，先选上第一个候选。正面一定要有，别的可以不填。
  - 用到这台 ComfyUI 上没装的节点，当场列出来，照样能导进来。
- **出图设置**：
  - 多了「工作流」下拉。选了导入的，底模、LoRA、步数、CFG、采样器、调度器不显示，照工作流里的。
  - 缺插件的当场标出来。面板底部的按钮上写「工作流「名字」」。
- **出图**：
  - 整份工作流发过去，只换正面、负面、种子、尺寸，别的照原样。正面照样加系列固定开头和评级词，负面照样加系列默认负面词，种子照内置流程依次加 1。
  - 框下面那一组、大图参数里写着用的哪个工作流，底模这些写「按工作流里原来的」。
  - 缺插件的一张都不发，说出工作流要用、这台没有的节点类型，比如「SAMLoader、FaceDetailerPipe」。

## 做了什么：AutoDL

规则在 `docs/dev-plan.md` 5.17。

- **设置「ComfyUI」**：
  - 出图用哪台：局域网那台或 AutoDL 实例，只记在这台电脑上。
  - AutoDL 一节：填开发者 Token，存好后输入框清空，只存在这台电脑的 `config.json`，接口返回时打码。
  - 从账号里列出实例，写着名字、地区、显卡、每小时多少钱；关机超过一天的写还有几天会被释放。
  - 状态和开机、现在关机、别开了三个按钮；空闲多久自动关机，5 到 240 分钟，默认 15。选的实例和分钟数存在工作文件夹，两台电脑共用。
- **顶上的状态**（画布、首页、设置三页都有）：
  - 用 AutoDL 时写已关机、正在开机等了几秒、运行中几分钟后自动关机、开机失败。开着时用醒目的颜色。
  - 用局域网那台、AutoDL 又开着时，另外标「AutoDL 也开着」。
  - 点开能切换用哪台、开机、关机（先问一句）、别开了。
- **出图设置**：「用哪台 ComfyUI」能切换，旁边写那台现在怎样。
- **出图**：
  - 实例关着时点生图：先开机，每 5 秒查一次，开好了再等上面的 ComfyUI 连得上，然后发。超过 5 分钟算失败。
  - 等开机时框下面那组写「AutoDL 正在开机，等了 N 秒，开好了再排队」，格子和画布卡片上写「等开机」。
  - 开机失败的这组一张都不发，说清是 Token 不对、实例不存在、余额不够还是等太久，带 AutoDL 的原话。能「去设置」「改用局域网那台」「再出一次」。
  - 开着、ComfyUI 连得上的直接发。大图参数里写用的是 AutoDL。
- **自动关机**：程序这边最后一张图出完后开始算，空闲到点就关。实例不是程序开的、程序也没在上面出过图的，从程序看到它开着时算起。
  - 到点时 ComfyUI 的队列里还有任务（比如你在 ComfyUI 网页上直接出的图）就不关，每分钟再看一次；队列空了，再空闲够设定的分钟数才关。
  - 看不了队列（ComfyUI 连不上）照常关，连不上的 ComfyUI 谁也用不了。
- **退出时关机**：按 Ctrl+C 或关掉窗口时，这次开机是程序开的、又没见它关掉，先发关机请求再退出，终端里说一声关没关掉。

## 做完以后你让加的：自己写标签

规则在 `docs/dev-plan.md` 5.14，为什么这么定见 `docs/requirements-interview-image.md` 已定第 22 到 24 条。

- 生图节点输入框旁边多了「写标签」，打开一个空的标签编辑窗，联想、粘贴、插片段、调权重都和编辑框时一样。
- 「存成框」：不问模型，存成一个框。回复那一栏写「自己写的」，角落写「自己写的，没有调用 AI」，没有「重答」。能生图、编辑、打星、岔出。
- 「让 AI 优化」：旁边能写一句要求。先把写的存成框，再在后面发一条「优化上面这个框里我自己写的标签：……」，不写要求就用默认的那句。模型回一个新框，自己写的留着。
- 之后再问模型时，自己写的框当成你说的话发过去（「我自己写了一个框：」加原文），模型知道那是你写的。
- 原型里没有这个入口，按现有的编辑窗和输入框的样子加的。

## 和计划、原型不一样的地方

- **导入接口改成 `{name, file, graph, fill}`**：往哪填在导入窗口里认好、挑好，点「导入」才存，点取消不留文件。计划原来是先存再改。计划第 4 节（多记导入时的文件名）、第 7 节已经改了。
- **自动找往哪填多走了一步**：正面、负面中间隔着 ControlNet、合并条件这类节点时，也顺着找过去。认不准的先选上第一个候选，计划原来写的是让你选。计划 5.18 已经改了。
- **缺插件只说缺哪几种节点，说不出是哪个插件**：「导出（API）」的 JSON 里没写节点来自哪个插件。原型写的是插件名「ComfyUI-Impact-Pack」。
- **说缺插件之前先重读一次节点列表**：列表是缓存的，这样刚装好插件的不用手动刷新。原型写的是「装好后去 ComfyUI 一节重新读列表」。计划 5.18 已经补上。
- **认不准时的导入窗口里也有「名字」一栏**：原型只在四处都认出来时有。
- **工作流里既有预览又有存图时，取最后一张存图**：计划 5.19 已经补上。
- **工作流的名字不能重**：跟片段库一样。
- **内置流程那张卡片的说明去掉了「放大、修脸、参考图生图都只用这套」**：这几样 P12 才有。
- **修了一个 P10 就有的问题**：改了出图设置马上点「生图」，服务端可能还按旧设置出。原因是界面先改、存盘在后面排队，点生图时没等存好。现在点生图先等刚改的存好。这是端到端测试抓到的。
- **又修了两处 P10 就有的问题**，都是打开时先去读已存的设置，读得慢时把刚填好、选好的盖掉：下载窗口把刚选好的文件夹盖回「还没选过」；设置「ComfyUI」把刚填进去的局域网地址盖成空的。现在读回来时不盖掉已经填好、选好的。也是端到端测试抓到的，这次页面打开时多了查 AutoDL 的请求，更容易碰上。
- **正在出的格子不写「0/0 步」**：导入的工作流不知道一共几步，ComfyUI 推来第一步之前只写「正在出」。
- **AutoDL 没选实例时那一项照样在**：`settings.json` 里 AutoDL 一直有，没选实例时实例那项是 null，空闲分钟数能先填。计划第 4 节改了。
- **多了三种状态**：原型只有已关机、正在开机、运行中、开机失败。另加「正在关机」（关机要几秒）、「查不到状态」（Token 不对、实例被释放）、「还没设置」（没填 Token 或没选实例）。
- **退出时关机也管关掉窗口**：计划写的是 Ctrl+C。Windows 上关掉终端窗口时程序有几秒可以发关机请求。
- **电源图标是补画的**：原型里开机关机按钮用了这个图标，但没画。
- **点了「别开了」**：原型只说开机请求会让它开好后马上关掉。等着开机的那几组算叫停。计划 5.17 补上了。
- **LoRA 下拉能按名字搜**：原型是普通下拉。你那台 AutoDL 上有 366 个 LoRA，翻不过来，你后来让加的。点开是搜索框加列表，几个词用空格隔开、都对得上才列出来，上下键挑、回车选。计划 5.14 补上了。
- **弹出的小窗打开时，焦点放进里面的搜索框**：之前「插片段」的搜索框打开时没拿到焦点，要先点一下才能打字，原因是小窗刚出来那一下是藏着的。和 LoRA 的搜索框一起修了。

## AutoDL 那一半：开工前要核对的

你确认了那台就是 AutoDL Art 上租的实例，所以计划 5.17 用的 AutoDL Art 接口（`www.autodl.art`）是对的。

计划要核对的三件事都有结果了。第三件是用 SSH 上去只读查的，没有关机再开，没多花钱：

- 访问地址要不要另外鉴权：不要，拿到地址就能用（之前的调研）。
- ComfyUI 跑在哪个端口：6006，只监听实例本机，经 AutoDL 的 8443 地址转出来（之前的调研）。
- 开机后 ComfyUI 会不会自己起来：会。是镜像的开机脚本拉起来的（`/root/zealman-app/start-comfyui.sh`，上一级就是容器的 1 号进程），不用手动开。
  - 今天这次：16:20:58 开机，16:21:18 ComfyUI 进程起来，16:22:34 开始接任务，一共 1 分 36 秒。
  - 今天前两次从进程起来到能接任务是 34 秒和 39 秒。
  - 计划里开机等 5 分钟算失败，够用。

拿到 Token 后只读地调了一次真接口，没开机也没关机：

- 列出你账号下 2 个实例，zealman-ComfyUI 那台查到的状态和 6006 访问地址都对得上。AutoDL 本站那套接口一个实例都没列出来，所以用 AutoDL Art 的接口是对的。
- Token 不对时返回 `AuthorizeFailed`「登录超时，请重新登录; 登录失败，请重试」，实例不存在时返回 `RecordNotFoundError`「未查询到相关实例」，HTTP 都是 200。假接口照这个写。

实例开着时，又用它真出了一张 IL 的图。没开机也没关机，开机、关机的请求在跑的脚本里拦着，一次也没发出去：

- 状态查到运行中，6006 的访问地址加上 https 直接能用，读节点列表 5.7 秒。
- 底模空着，按规则用了这台上第一个 IL 的（`Illustrious/oneObsessionBranch_v7Matureeps.safetensors`），832×1216，出图 34 秒，图是好的。
- 从点生图到出完 3 分 41 秒，前 3 分钟在排队：那台 ComfyUI 上正跑着别的视频任务。开始跑、出完都是 ComfyUI 推来的，经 AutoDL 的 8443 地址也收得到。

## 没做的和疑问

- 真实例上没开过机、关过机（开机就扣钱），留给你验收 11.3 第 4 条：关着时点生图自动开机出图；空闲到点自动关，到控制台确认；开着时 Ctrl+C 退出，实例被关掉。
- 按 Ctrl+C 时先关机：在这里发不了 Windows 的 Ctrl+C，只测了关机那一步。验收时看终端最后一行写没写「已经让它关机了」。
- 每小时的价格是按千分之一元算的：快照里是 1680，显示 ¥1.68/小时。你在控制台对一下。
- 余额不够时 AutoDL 返回什么 code 文档没写，按原话里有没有「余额」认。认不出时照样带原话，只是不说是余额不够。
- 空闲到点时才看 ComfyUI 的队列。倒计时中间你在 ComfyUI 网页上出完了图、到点时队列正好空着，照样会关。
- AutoDL 关着时，出图设置里列不出底模和 LoRA（要从开着的 ComfyUI 读）。程序这次开过机、读过一次的照样能选；重启程序后要开过一次机才有。底模空着时出图用这个系列的第一个。
- 现在有三份改动没提交：「Danbooru 撤了的标签算认识」、P10、P11。开始 P11 前我给 P10 留了一份底，没动分支。你说「提交」时能分成三次提交。
