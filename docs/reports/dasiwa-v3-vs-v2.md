# DaSiWa V3 和 V2 画 2D 动漫对比

10 月 8 日在 A 上跑的。结论：画风基本一致，同一套参考图出来都是「动漫脸的女主 + 半写实的街道和路人」，换 V3 没让画面更像 2D 动画。差别在颜色、构图和脸，见下面。

## 怎么试的

- 参考模式，参考图两张：`image__00055_.png`（脸）、`image__00072_.png`（全身和衣服）。这两张是平涂感比较强的二维插画。
- 原话：傍晚挂着灯笼的商店街，她拎着面包从店里出来，看到镜头挥手小跑过来，说「久等啦，我们走吧！」，身后有骑车的学生和提购物袋的阿姨；加了一句「严格按照参考图的二维动画风格来，人物、街道、路人都画成同样的二维动画」。
- 写提示词的模型只写一次，两条用同一条回复、同一个种子 20261008、同样的加速步数（一采 10 步、二采 3 步）、15 秒、一采 864×480 出片 1728×960，只换主模型：
  - V2：`minimax/DasiwaMinimaxH3_dasiwaHybridTurboV2_int8.safetensors`（画布现在默认的加速版）
  - V3：`minimax/dasiwa_minimax_h3_ref2va_v3_pruned_hybrid_turbo_int8_row-wise_convrot_runtime_mixed.safetensors.safetensors`（V3 加速版）
- 脚本 `outputs/v3-vs-v2/run.mjs`，走的是本机程序的接口。V3 用画布现在的接法能直接加载，不用改流程。

## 看到的

| | V2 | V3 |
| --- | --- | --- |
| 整体画风 | 女主是光泽很重的 2.5D 动漫渲染，街道、店里的面包、路人接近写实 | 一样的路子；颜色更饱和，灯笼更橙、天更蓝，看着更干净 |
| 女主的脸 | 眼线重、红唇、阴影明显，成熟感和参考图的脸更像 | 脸更圆、妆淡、笑得更开，偏一般的萌系动漫脸，和参考图的成熟感差一点 |
| 衣服身材 | 西装、白内搭、短裙、丝袜、腿环都在 | 同样都在 |
| 路人 | 半写实，阿姨、骑车的学生像真人照片加了点滤镜 | 也是半写实，骑车的学生稍微动漫一点，整体差不多 |
| 构图 | 开头就在面包店门口，景别近 | 开头是整条街的大远景，头顶拉着一串串灯笼，她从远处的店里出来，更贴「一排灯笼」 |
| 动作 | 出门、挥手、走过来、抱着面包说话，都做了 | 都做了，跑过来的动作更有劲 |
| 声音 | 12 到 14 秒说台词，女声 | 同样 12 到 14 秒说台词，女声 |
| 用时 | 472 秒 | 472 秒，一样快 |

- 同一个种子换了模型，镜头不会一样，所以构图差别不说明谁好谁坏，只能看画风。
- 两条都没把街道和路人画成参考图那种平涂二维动画，和之前「街头偷拍」那次看到的一样：参考图只管得住女主本人，别的东西画成什么风格由模型自己定，提示词里写画风压不住。
