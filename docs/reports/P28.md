## 做了什么

### 1. 转真人（作者那条路，参数一字不改）

新增 `packages/shared/src/krea2Real.ts`：照那份工作流的接线和参数搭图。

- `UNETLoader` → `LoraLoader`（转真人 V3 + 人物 LoRA，**model 和 clip 一起喂**）→ `Krea2OstrisEditModelPatch(kv_cache=true)`
- 图 1 / 图 2：`LoadImage` → `ColorCorrect(饱和度 −20)` → `ImageScaleByAspectRatio V2`（长边 1536、`round_to_multiple None`）
- `Easy_QwenEdit2509`（`auto_resize=crop`、`vl_size=384`、`image1`/`latent_image` = 图 1、`image2` = 图 2（双图关时退回图 1）、`image2_strength` 可调）
- 正负 conditioning 都过 `FluxKontextMultiReferenceLatentMethod(index_timestep_zero)`
- `KSampler(euler, **beta57**, 8 步, CFG 1, denoise 1)` → `VAEDecode` → `PreviewImage`
- 反推开着时才生成 `llama_cpp_model_loader`（35B MoE IQ2_M + mmproj、`chat_handler=Qwen3.6`、`n_ctx=8192`、`force_offload=false`）→ `llama_cpp_parameters` → `llama_cpp_instruct_adv`（系统提示词 = 反推那两份，**原文抠自 `docs/krea2-real-reverse-prompt.md`**，另有一条测试从 doc 里抠出来逐字比对，防止两边漂）
- 反推关着时：我们自己拼 `[双图/单图触发词, 手输那句]`（触发词一字不改）
- 无审查是默认：底模 `moodyAmateurMixKrea2_3JAVStyle_int8`、文字理解 `qwen3vl_4b_uncensored_int8_convrot`

### 2. 换装

还是编辑档那条路（Ostris 两个节点），只把 LoRA 换成 `krea2/krea_outfittransfer.safetensors`；`EDIT_PRESETS.outfit` 给了四条现成的句子。

### 3. 面板

「转真人」「换装」在功能下拉里能选了（局部重绘仍标「还没做」）。转真人的参数区照原型和布局稿：**谁写词**（反推 / 手输 + 8 个辅助词）、**做法**（只转真人 / 换脸 + 图 2 强度 + 图 2 是哪张）、**LoRA 两组**（转真人下拉+强度、人物可加多个）、**版本**（只留无审查这一档）、尺寸说明。图槽能标图 2「真人参考」（右键指定、点它两张对调）。

### 4. 接口

`POST /edit` 收 `{ fn, slot, slotB, text, refBoost, real, inpaint }`，**缺的字段拿节点上存的那份设置当底**（只发 `{fn}` 也照节点走）——这条是集成时抓出来的坑，见下面。

## 集成时抓出来的坑（都是 Lead 收尾时修的）

1. **`POST /edit` 只带 `fn` 时会把节点的设置悄悄换回默认值** —— 原来请求里的字段就是唯一来源、缺的按默认补。真机第一次跑「双图」时 `Easy_QwenEdit2509.image2` 接的是图 1（双图没生效），就是踩在这上面。改成：**节点上存的设置当底、请求里的字段覆盖**（`editRequestOf(req, editSettingsOf(node.edit, ...))`）。
2. **插件名报错了两个**：`llama_cpp_*` 在那台上是 `llama-cpp_vllm`（不是 `lihaoyun6/ComfyUI-llama-cpp_vlm`）；`ColorCorrect` 来自 `comfyui-art-venture`（不是 `ComfyUI_LayerStyle`）。按实机 `object_info` 的 `python_module` 核过改掉。`FluxKontextMultiReferenceLatentMethod` 确认是 **ComfyUI 本体**自带（`comfy_extras.nodes_flux`）。
3. **mock 的 LoRA 清单加长了**，`11-images` 那条「按名字搜」的期望清单跟着补；`20-edit-node` 那条「转真人（还没做）」的断言改成「三个功能都在菜单里、局部重绘还标着还没做」。

## 真机验证（同一台 `pro-79110c14fb03`，报告 `docs/reports/real-machine-edit-node.md`）

拿同一张图 1（动漫雨夜女孩）、同一张图 2（写实人像）跑，和作者那套原样跑的基线对照：

| 跑法 | 用时 | 出图 |
| --- | --- | --- |
| 作者那套（手搭 API 图，手输触发词） | 80 秒 | 1048×1536 |
| 作者那套（反推） | 38 秒 | 1048×1536 |
| **我们 · 反推 + 双图** | 30 秒 | 1048×1536 |
| **我们 · 手输 + 双图** | 21 秒 | 1048×1536 |

**还没验的**：~~`image2_strength` 这个旋钮到底有没有用~~ —— **已验**：0.3 / 0.6 / 1.0 三档出来确实不一样（1.0 时发色变暖、脸更圆、背景偏暖，往图 2 靠；0.3 最像图 1 真人化），但**它不是换脸**，1.0 也拿不到图 2 的具体五官。见 `docs/reports/real-machine-edit-node.md`。
