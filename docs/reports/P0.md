### 服务端

- 只监听 127.0.0.1:3711。
- `GET /api/config`：密钥有值的一律返回 `******`。
- `PUT /api/config`：只改请求里带了的 `workFolder` 和 `modelConfigs`，其他字段不动；密钥传 `******` 表示不改。
- 设工作文件夹时：必须是完整路径，文件夹不存在就新建；建好 `prompts/.history`、`canvases`、`.trash`，把模板复制成 `prompts/default.md`，已经有了就不覆盖。初始化失败不保存配置，返回原因。
- `POST /api/llm/test`：测试连接，返回 `{ok, error?}`。
- `POST /api/assets/pick-folder`：弹 Windows 选文件夹窗口，点取消返回 `{path: null}`，其他系统返回 501。
- `npm start` 时托管打包好的前端，`/api` 以外的页面地址都返回前端页面，并打开浏览器。

### 计划没写死、我定下的几件事

- 测试连接发一条极短的消息，而不是调 `/v1/models`。做法是发 `ping`、流式，收到响应头就断开。原因：`/v1/models` 查不出模型名填错；收到响应头就断开几乎不耗 token，推理模型也不用等它想完。
- 接口地址要带版本号，比如 `https://api.openai.com/v1`，程序只在后面接 `/chat/completions`。原因：各家文档给的地址本来就带版本号，而且不全是 `/v1`（火山方舟是 `/api/v3`，智谱是 `/api/paas/v4`），程序固定接 `/v1/chat/completions` 会接错。输入框的占位文字写了例子。
- 「选择」按钮 P0 就做了，因为 6.4 设置页写了它，接口用计划里的 `/assets/pick-folder`。弹的是 Windows 老式的树形选文件夹窗口；想换成能粘贴路径的新式窗口要多写一段代码，现在输入框里也能直接粘贴路径。
- `npm run dev` 同时起 mock-llm，省得再开一个终端。`npm run dev` 不自动开浏览器，`npm start` 才开。`npm start` 每次先打包前端，另一台机器拉了新代码直接 `npm start` 就是最新的，代价是启动多等几秒。
- 首页没设工作文件夹时跳设置页、首页顶部的路径和「设置」入口，第 8 节没说归哪个阶段，P0 的流程离不开，就在 P0 做了。
- 端到端测试的服务用 3712 端口，本机配置和工作文件夹放在系统临时目录的 `media-agent-e2e` 下，每次跑前清空，不影响开发中的服务和你的真实配置。
- 依赖版本：Playwright 固定 1.62，因为这台机器已经装了它用的浏览器，不用再下载；React Router 用 7，因为 8 要求 React 19，计划定的是 React 18；其余用当前最新版（TypeScript 7、Vite 8、Vitest 5、Express 5）。
- mock-llm 回复里 `summary:` 单独一行、内容在下一行，和默认系统提示词要求模型的写法一样，这样端到端测试走的是真实回复的格式。计划 9.1 原文是「`summary:` 那行写…」，也能理解成写在同一行；5.5 的解析规则两种写法都能取到概述。
