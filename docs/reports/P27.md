# P27：图像编辑节点 E3 —— 模型参与

2026-10-11。计划见 `docs/plan-image-edit-node.md` 的 E3 那一行、`docs/dev-plan.md` 5.36。

用户原话：「有的节点编辑我还想让模型参与帮忙写提示词」「编辑节点是独立的一个选项…其实是我选的每一个功能，每个功能都有相应的提示词」「模型在选的时候，不要让它连着功能一起定」。

## 做了什么

### 1. 「模型提示词」那一行露出来了

编辑节点的面板顶栏那一格，原来写着「系统提示词」、四套编辑提示词全列在下拉里，让人以为要自己挑。现在：

- 这一格叫 **模型提示词**（`aria-label` 和可见的小字都是），只列**当前功能那一份**（说明段里 `功能:` 对上的那份）。
- 换功能（E4 起界面上能换）服务端**自己**把 `systemPromptName` 换成那个功能那一份；请求里明写了系统提示词的照请求里的来。
- 一份都没对上（用户把那份删了、或者手改成别的用途了）时，下拉里显示现在用的那个名字 + 「不是给「X」写的」，不拦着用。

对应代码：`promptNameForFn`（`packages/shared/src/edit.ts`）、`canvasRoutes` 的 PATCH（`packages/server/src/routes/canvases.ts`）、`Drawer.tsx` 的 `cfgSys`。

### 2. 模型看着选中的那张图写

编辑节点发消息时，发给模型的图**只有选中的那一张**（`editDiff`，`packages/shared/src/slotDiff.ts`），并带一句「要改的是第 N 张参考图。」；没选图时说「还没有选要改的图。」。不再走生图节点那套「槽位 diff、新增参考图」。

面板底下「有改动还没发出去」那句也跟着换了：编辑节点上说「要改的是第 N 张参考图」，不说「新增参考图」。

### 3. 候选框：「用它」+ 角标

每条回复上记下 `message.edit = { fn, slot }`（写这条框时是哪个功能、看着第几张图）：

- 框右下角标着 **`指令编辑 · 用 1 号图`**。
- 框上一排第一个按钮是 **「用它」**（强调色）：把框里那句话落到编辑栏的「要改什么」，**功能、图也一起切回写这条框时的那套**。那张图已经不在槽位里了就退回现在选中的那张，并提示一句。
- `复制 / 翻译 / 打星 / 手动改 / 上传清单 / 沿这个方向继续` 照旧（编辑节点本来就有）。

### 4. 输入框旁多一个「写一个」

不问你要改什么，直接发一句 `看图，按「指令编辑」给我写几个方向。`（`editWriteOneText`），模型看着选中的图给 2–3 个方向。

### 5. 假模型认得出编辑那四套

`tools/mock-llm` 按固定格式要求里那句「**一个字都不会被程序改动**」认编辑节点（跟生图那两套一个道理：拿提示词的措辞认会一改就崩），四个功能回四句不一样的话，测试靠它卡「换了功能真的换了提示词」。

## 踩的坑

1. **放图是先改本地再写服务端**（`place()` 没被 await）。e2e 里放完图马上发消息，服务端读到的还是空槽位——第一次跑就挂在这上面。现在测试里等 `GET /nodes/:id` 的 `slots` 真的到位再发。
2. 编辑节点的输入框旁原来会跟着生图节点一起冒出「**写标签**」按钮（那是自己写一串 Danbooru 标签变成一个框，编辑节点框里放的是那句话，不是标签）。改成只有生图节点才有。
3. 候选框上的「**用它**」不能只把文字填进去：那条框是某个功能、看着某张图写的，功能和图得一起切回去，所以回复上必须记 `{ fn, slot }`——这是 E3 里唯一一个改数据结构的决定。

## 没做的

- **框上的「开始」**（每个候选框自己就能出图，出的挂在它下面）：计划里有（布局稿第 4 节 ④），这一轮没做，留给 E6 收尾那批。
- **界面上还换不了功能**：另外三个功能（转真人 / 换装 / 局部重绘）在菜单里仍标着「还没做」，所以「换功能 → 换模型提示词」这条在 e2e 里是**调接口**换的；E4 把三个功能做出来之后就点得到了。
- 真机验证不在这条报告里，单独一份：`docs/reports/real-machine-edit-node.md`。
