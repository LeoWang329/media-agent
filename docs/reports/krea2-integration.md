# Krea2 集成验收报告

日期：2026-10-08。在 `main` 实现 Krea2 文生图和四视图集成。

需求见 `docs/requirements-interview-krea2.md`，使用方法和完整默认参数见 `docs/dev-plan-krea2.md`。

## 完成内容

- 新增 Krea2 生图系列，系统提示词选 `krea2`。模型写英文段落，框能编辑、翻译、打星和生图；不拆 Danbooru 标签，不拼质量前缀、评级词或负面词。
- 文生图按 T01 参数，底模、文字理解模型、VAE、多 LoRA、步数、CFG、采样器、调度器、种子、张数与尺寸可改。LoRA 实际串入模型。原流程未连接的 darkbrush 不默认启用。
- 四视图按 T10 参数，默认 1536×1024，参考图可从槽位或生成结果选，相似度可调。固定四视图指令在前，框中文字追加为额外要求；接上 `target_latent`。
- 槽位菜单、生成图按钮和大图窗口提供“做四视图”。所有生图系列可用，不调用 LLM。槽位图新建“四视图”框，生成图的结果挂回原框。IL/Pony 节点的系列和设置保留。
- 两种模式均提供常用尺寸预设与自定义宽高。文生图原尺寸为 1536×2728；自定义 64–4096，文生图按 8、四视图按 16 的倍数。
- Krea2 预设按系列独立保存，不保存参考图、张数和种子。继续使用既有队列、进度、下载、重出和 AutoDL 机制。
- 旧工作文件夹自动补入 Krea2 提示词，同名文件保留用户修改。设置页能查看 Krea2 专用格式要求，不显示该系列不生效的负面词、评级词和 clip skip。

## 验证边界

项目 `AGENTS.md` 要求：“测试只用 mock-llm 和 mock-comfyui，不调真模型，不连真的 ComfyUI 和 AutoDL。”本次没有真实模型或 GPU 调用，模型调用费用为 0。

因此目前确认的是代码流程、接口结构、参数传递、文件内容、任务归属与页面交互。真实出片质量、GPU 显存占用和相似度 1 与 4 的效果对比尚未验证；相似度默认保留原 T10 的 1，可在页面改成 4。

当前仅支持 Turbo。Raw、Krea2 放大、部位重绘和 ControlNet 不在本期范围。
