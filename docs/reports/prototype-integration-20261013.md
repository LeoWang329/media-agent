# 改图原型功能接入 · 2026-10-13

实现基线：`main` 的 `b51db72` 与用户更新后的 `web/prototype/canvas.html`。本报告随本轮功能接入一并归档。

## 已接入

- 改图节点按原型分为创作、执行、结果；复用真实对话、版本、素材和生成任务，没有接入原型里的模拟回复与计时生成。
- 八种操作均通过现有后端工作流执行：指令编辑、转真人、换装、局部重绘、深度迁移、Remix、放大高清、四视图。
- 新回复不覆盖执行文字。选择候选保留当前操作与参数，并绑定原图；原图缺失或不同会阻止提交，明确复用文字后解除绑定。修改候选产生版本，历史任务保留。
- 支持固定/随机出图种子、独立反推种子、掩码持久化与撤销重做、0–128 像素羽化、最高 2 的深度控制、换装 LoRA、2/4 倍放大与自定义四视图尺寸。
- 转真人仍遵循标准工作流：Moody-Mix premium、FP8、V3 与 body LoRA、Easy_QwenEdit2509、8 步、CFG 1、euler/beta57、长边 1536。手输/反推和单/双图分别控制；反推实际文字存入结果。
- 结果汇总全部候选版本的任务，支持进度、停止、失败详情、收藏、完整图比较、下载、同参数重出与只换种子。文件缺失单独显示，不把完成任务改成失败。
- 继续创作必须先保存源结果，通过既有上传链路复制到素材槽位，记录源任务与候选归属，原结果不被替换。放大或反推产生的无文字候选结果也支持派生；服务端核对源任务与归属，防止挂到无关候选下。
- 节点上下文轮数与思考覆盖影响后续请求，岔出时保留。用途固定，具体提示词仍按操作选择。
