# P7 撤销 报告

## 做了什么

画布上按 Ctrl+Z 退回上一步，Ctrl+Shift+Z 再做一遍，最多记 50 步。

- **能撤销的**：拖动节点、折叠和展开、自动排整齐、删除节点（连同子节点）、重命名、槽位里放图删图调顺序换图、视频时长、画面比例。
- **不进撤销栈的**：发出去的消息（发送、重新生成、编辑、fork）、草稿、换模型配置和系统提示词。
- **在输入框和提示词编辑器里打字时不抢 Ctrl+Z**，那里交给编辑器自己的撤销。
- **换画布、重新打开同一个画布，栈都清空**，不会把上一个画布的操作撤到这个画布上。
- **删掉的节点从回收站挪回来**：删的时候整份移进 `.trash/<时间>-nodes-<节点 id>/`，里面带一份清单记着是哪个画布、几个节点、各自在画布上的位置；撤销就按清单挪回去。同一个节点再删一次会进新的回收站文件夹，栈里记的名字跟着换。

栈里的一步就是两个函数：怎么退回去、怎么再做一遍。它们调的都是不记栈的内部写法，所以撤销和重做自己不会又被记一遍。每一步都是先记栈再写服务端——界面在服务端答完的那一刻就变了，要是等写完再记，中间这段时间按 Ctrl+Z 会退到上一步去。

## 路上修的两个老毛病

这两个都不是撤销带来的，是跑新用例时露出来的，各自影响的范围都比撤销大：

1. **Windows 上存文件偶尔失败，那次改动就丢了**。所有写文件的地方都是先写临时文件再改名，而 Windows 上杀毒软件、搜索索引会短暂占住刚写好的文件，这时候改名会报 EPERM，画布顶上弹一条报错，位置就没存上。八遍用例里抓到两次。改法是改名失败就等一下再试，最多五次、加起来 0.3 秒（[jsonFile.ts](packages/server/src/store/jsonFile.ts)）。画布位置、节点内容、图片副本、拼图都走这里。
2. **正在拖节点的时候后台刷新会把它拽回原处**。回复发完那一下会重新读一次画布，读回来的位置盖掉了手上正拖着的位置。改法是正在拖的节点不跟着刷新走（[CanvasView.tsx](packages/client/src/components/CanvasView.tsx)）。
