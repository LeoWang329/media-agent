# P14 生图节点和视频节点分开报告

这一步做完了。规则在 `docs/dev-plan.md` 5.23，为什么这么定见 `docs/requirements-interview-image.md` 已定第 32 到 34 条。

## 做了什么

- **节点多了类型**：视频节点或生图节点，建的时候定，之后不能改。面板、发给模型的说明、接哪份固定格式要求、卡片上的字都看类型，不再看系统提示词是哪种用途。生图节点的系列（IL 或 Pony）照旧看它选的系统提示词。
- **新建**：工具栏的「新建节点」点开一个小菜单，两项「视频节点」「生图节点」。视频节点用 `ref2va`，生图节点用 `il`；`il` 删了用排在最前的生图提示词；一套生图提示词都没有时，点「生图节点」不建，提示「设置里还没有生图用的系统提示词」。
- **系统提示词的下拉只列这种节点用的**：生图节点照旧能在 `il` 和 `pony` 之间换，系列跟着换。服务端收到另一种的返回 400。换的时候只提示「从下一条消息起用系统提示词「X」」，原来「这个节点变成生图节点」那两句去掉了。
- **岔出来的节点和原节点同一种。**
- **节点用的系统提示词删了，或者用途改了**：类型不变，下拉里显示「（找不到 X）」或「（X 不是生图节点用的）」，换一套同种的就好。
- **已有的节点**：读的时候按现在用的系统提示词归类，下次存的时候写进文件。你工作文件夹里的老节点不用动。
- **卡片**：视频节点标「视频」，生图节点照旧标「生图 · IL」；生图节点的边框是紫色，选中时照旧是蓝色。紫色是新加的颜色，明暗两套都有。
- **设置的系统提示词列表**：两组的说明改成「写视频提示词 · 视频节点用」「写生图标签 · 生图节点用」。

## 和计划不一样的地方

- **没有生图提示词时，「生图节点」照样能点，点了不建、说原因**：计划原来写的是灰掉。这样菜单不用等提示词列表读完，也少一种状态。计划改过了。
- **顺手修了一处 P9 起就有的显示**：生图节点里，用户消息下面也写着「8 秒 · 16:9」，这两样根本不发给模型。现在生图节点只写带了几张图。计划 5.23 加了一句。
