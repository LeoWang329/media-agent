### 服务端

- `POST /canvases/:id/nodes/:nid/messages/:mid/star {promptIndex, on}`：星记在 `message.stars` 里，返回整个节点。卡片的星按 5.9 算：这个节点任何消息、任何版本有星就显示。
- `POST /canvases/:id/nodes/:nid/messages/:mid/edit-prompt {promptIndex, text}`：按 5.2 在同一个父消息下新建一条 assistant 版本，正文是原全文里把那个框的内容换掉，重新解析，`editedFromMessageId` 指向原来那条，不调模型。找不到那个框返回 404。
- `GET /canvases/:id/images/:iid/checklist-path`：按 5.7 算这张图该传哪份——没处理过、原文件还在就给原路径；否则给画布副本，并带一句说明。
- `POST /assets/reveal {path}`：Windows 上执行 `explorer /select,<路径>`，mac 是 `open -R`，其他系统打开所在文件夹。路径同样要在导入的资产文件夹或工作文件夹里，否则 403。
- `GET /prompts/:name/history/:hash`：读 `prompts/.history/<name>-<hash 前 12 位>.md`。版本号格式不对 400，没这一版 404。

### 计划没写死、我定下的几件事

- 手动改出来的新版本，`usage` 不带过来（这一版没花 token），星、当时用的模型和提示词版本照旧带着——那些说的是这段文字从哪来的。
- 从 Windows 文件夹拖进来的图没有本机路径，上传清单里给画布副本，说明写「拖进来的图，用这份」。计划 5.7 只写了「已处理，请上传这份」和「原图不在了，用这份」两种。
- 「提示词里没用到」这个灰字，计划写的是「行首」，我放在了文件名后面：行首是缩略图，标签放那儿反而看不出是说哪一张。想挪到最前面说一声。
- 回复角落只有在这条消息记下了模型名或提示词名时才显示；P1、P2 期间发的消息都记了，不受影响。
- token 显示成「提示 + 回复」两个数字相加的样子，没有折算价格。

## 怎么试

服务还开着（`npm run dev`，改完自动重启），直接刷页面。

1. 在一个节点里发一句话，回复里的提示词框下面现在有五个按钮。
2. 点「★」：框标题和画布卡片右上角都出现星；再点一次取消。
3. 点「编辑」：框变成文本框，改几个字，点「保存」——回复上出现 `‹ 2/2 ›`，卡片概述跟着变；点「复制」粘出来是改过的；点「‹」切回第 1 版，复制到的是原来的。
4. 点「上传清单」：每张图一行，没处理过的图给你原文件路径，超过 5760 像素或从文件夹拖进来的给画布副本并写明原因；「在资源管理器中显示」会在你屏幕上弹出资源管理器并选中那个文件。
5. 回复下面那行灰字：点提示词名「default」，弹窗显示发这条消息时的提示词全文；之后改了 `prompts/default.md`，旧回复点开看到的还是旧版。
