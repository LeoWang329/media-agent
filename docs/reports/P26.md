# P26 图像编辑节点 · E2（面板底部的编辑栏）

接着 E1（[P25](P25.md)）往下做第二步。规则在 [dev-plan.md](../dev-plan.md) 5.39，界面照 `web/prototype/image-edit-node.html`。

用户原话（这一轮之前陆续定的）：功能做成下拉、每个功能一套系统提示词而且能选、模型不许连着把功能也定了、第一轮所有功能都做、无审查当默认。

**E2 做的事**：把编辑栏接上去 —— 功能 → 图 → 提示词 → 参数 → 开始，从「能建出节点」到「放一张图、写一句话、能出图」。

## 做了什么

### E2a 共享层：功能表和设置

- `packages/shared/src/edit.ts`（新）：`EDIT_FNS`（四个功能：id、名字、角色名、要几张、说明、这一轮做没做）、`EDIT_PRESETS`（每个功能的现成句子）、`defaultEditSettings()`、`editSettingsOf()`。
  - **功能名必须跟系统提示词说明段里的「功能:」一模一样**（编辑节点按它挑提示词），所以 `name` 就是 `指令编辑 / 转真人 / 换装 / 局部重绘`。
  - `editSettingsOf` 顺手处理两件事：老节点没有编辑设置时给默认值；选了第 5 张但只剩 2 张了收回第 1 张。
- `types.ts`：`EditFnId`、`EditSettings`（功能 / 槽位 / 那句话 / 相似度），`ChatNode` 加可选的 `edit`。
- `krea2.ts`：`kreaEditSetup()` —— **指令编辑借编辑档的接线，但挂身份编辑 v1.1 的 LoRA**，不挂动漫转真人 V3。

### E2b 服务端：点「开始」建一组任务

- `POST /canvases/:id/nodes/:nid/edit`，收 `{ fn, slot, text, refBoost }`（校验：功能认得、槽位是整数、相似度 0–10）。
- `jobs.editJob()`：照 `fourView` 那套 —— 自己造一条 assistant 回复（`<prompt label="指令编辑">` 里就是那句话、`handwritten: true`、带上槽位快照），再把任务挂上去，出的图就长在框下面。
- `jobs.editParams()`：走 Krea2 编辑档。没选图报「先选一张要改的图」，没写字报「先写一句要改什么」，功能还没做报「「转真人」还没做，下一批上」。
- 校验层的 `editSettings`（`PATCH` 用），`applyNodePatch` 收 `edit`。

### E2c 前端：编辑栏

- `canvas/EditPanel.tsx`（新）：`EditFnBar`（功能下拉 + 两行说明）和 `EditStartBar`（提示词下拉 + 正文 + 相似度 + 开始）。
- `Dock.tsx`：编辑节点按 **功能 → 图 → 提示词 → 开始** 排；槽位点一下就是「用这张图」（单选），选中的底下标角色名，**原来的菜单挪到右键**；这一行不再显示尺寸和张数。
- `imageActions.startEdit()`：等刚改的设置存好，POST 出去，服务端回来的节点和任务直接放进画布（照 `fourView`）。
- `PromptBox.tsx`：编辑节点的框下面也挂出的图（原来只有生图节点挂）。
- `Graph.tsx`：编辑节点的卡片写「N 张图」，不再显示「8秒 · 16:9」。
- `design/image.css`：编辑栏那几行、选中那张图的描边和角色名。

## 和计划不一样的地方

- **计划里说「指令编辑 = Krea2 编辑档（T07）：`Krea2EditModelPatch` + `Krea2EditGroundedEncode`」，这条是旧的，已改**。实际编辑档在 5.37 就换成 **Ostris 那条**了（`Krea2OstrisEditModelPatch` + `TextEncodeKrea2OstrisEdit`）——真机上验过 Krea2Edit 配写实/转真人 LoRA 会出花图，四视图没这个问题才继续用 Krea2Edit。计划文档里那三处提法都改了。
- **LoRA 的选择是个新决定**：编辑档的默认方案是「动漫转真人 V3」，但指令编辑不是转真人，挂它会**自动把真人化触发词加在最前面**（`editPresetOf` 认出来就加），「把外套换成黑色皮衣」这种话会被污染。所以指令编辑挂**身份编辑 v1.1**（照 T07 那个，方案里本来就有、没有触发词）。⚠️ 5.37 记着这个 LoRA 配 Ostris 这条路**没在真机上验过**，界面上要写「试了再说」——等有机器时和 E4 一起验。
- **功能菜单里「还没做」的三个照常列出来**（点了给提示）。中间踩了个坑：`MenuItem` 里带 `note` 的那种画成一行说明、**不是能点的按钮**，一开始把「还没做」写成 note 了，菜单里那三项就消失了。
- **E1 报告里那句「E2 之前底部先借用生图的尺寸张数」作废**：E2 直接把那里换成编辑栏了。
