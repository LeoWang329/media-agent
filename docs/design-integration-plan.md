# 设计原型对接方案

原型在 `web/Web-Prototype.zip`，解压在 `web/prototype/`。

## 原型里有什么

- `setup.html` 首次设置：三步（选工作文件夹 → 填模型配置 → 完成）。
- `home.html` 首页：画布卡片列表。
- `canvas.html` 画布工作台：节点图铺满全屏，工具条浮在上面，点节点从右边拉出对话面板。资产库、上传清单、拼图、系统提示词原文都是弹层，@ 选图是输入框上方的小窗。
- `settings.html` 设置：工作文件夹、模型配置、系统提示词、固定格式要求四个分区。
- 样式两份：`shared/app.css`（公共）、`shared/canvas.css`（工作台）。脚本七份，数据全是写死在页面里的假数据。

不进产品的：`index.html` 是原型自己的导航页；`img/` 是示例图；`review/` 是设计过程截图；`plugin-source/` 是设计工具生成的东西。

## 两种对接办法

### 办法一（推荐）：样式文件原样用，页面结构照原型一比一搬进现在的前端

- `app.css`、`canvas.css` 原封不动放进前端。页面的层级、类名、文案照原型的 HTML 写，图标用原型那套 SVG。
- 数据和逻辑沿用现在已经测过的：接口、消息版本树、流式回复、撤销栈、@ 引用编辑器（外观换成原型的小标签）、图片处理。
- 节点图不再用 React Flow，照原型的写法自己画（平移、缩放、拖动、连线）。React Flow 自带的外层结构和样式会让节点图和原型对不上。
- 设计师以后再改：纯样式的改动（颜色、间距、字号）换掉两个 css 文件就生效；改了页面结构的，要再搬一次。

### 办法二：原型的 HTML 和脚本原样上线，把假数据换成真接口

- 原型脚本是围绕一套内存里的假数据写的，对话存成「位置 + 版本 + 后续」的嵌套结构，和服务端存的消息树不是一个形状，几乎每个函数都要改。
- 流式回复、撤销、@ 引用、上传清单、图片处理状态都要在原生脚本里重写，现在的前端和它的测试就不要了。
- 好处是设计师以后改的 HTML 离线上更近。代价是工作量大约是办法一的两倍，改动面大，漏功能的风险也大。

## 原型比现在多出来的东西

照原型做，都要补上。标了「服务端」的要改一点后端。

### 首次设置

- 单独一页三步：选文件夹（下面预览会建哪些目录）→ 填模型配置 → 完成汇总。第一次打开跳这页，不再跳设置页。
- 文件夹不能写入时提示「这个文件夹不让写入：拒绝访问」。

### 首页

- 画布卡片有封面图、「N 个节点正在生成」。服务端：画布列表多返回封面图和正在生成的节点数。
- 删除画布后提示条上能「撤销」。服务端：加一个从回收站恢复画布的接口。
- 新建画布用弹窗，名字为空时提示；改名在卡片上直接改。

### 画布工作台

- 默认暗色，可切亮色，记在浏览器里。
- 左上：回首页、画布名点击改名、「已写入 17:42:05」写入状态。
- 右上工具条：新建节点、自动排整齐、撤销、重做（悬停提示能撤销的是哪一步）、资产库、主题、设置。左下缩放条：放大、缩小、回到 100%、显示全部节点。
- 节点卡片：最多 5 张缩略图加「+N」；生成中、请求失败、N 个方向三种标签；时长和比例；折叠时卡片旁边「收起了 N 个节点」可以点开；卡片上有「…」菜单。
- 点空白处收起面板；面板左边缘能拖宽，宽度记住。
- 删除节点、自动排整齐、删槽位里的图之后，提示条上带「撤销」。

### 对话面板

- 头部：从哪个节点第几条消息岔出（点名字能跳过去）、「标题手动改过，AI 不再覆盖」、这个节点一共花了多少钱。
- fork 来的那几条消息收成一块「从「某节点」复制来的 N 条消息」，点开才显示。
- 回复上的标签：「手动修改」「重答」「已叫停」。服务端：叫停时在消息上记一个标记。
- 提示词框按剧本排：段名做小标题，镜头号和时间点放左栏；超过 700 字先折起来；生成中底部显示「还没写完 · N 字」；叫停时没写完的框标「这条提示词不完整」。
- 失败的回复显示状态码、原因、时间和重试按钮。
- 用户消息：说明前面有「自动附加」标签，下面写这条带了几张图、几秒、什么比例；「改这句」就地编辑。
- 底部「有改动还没发出去」：预告下次会自动附上的那句话；重新编号时逐张列出原来几号、现在几号；「撤回改动」回到上次发出时的槽位、时长和比例。
- 槽位：点开是菜单（换一张、往前挪、往后挪、删掉这格）；角上标「处理过」「副本」；放图时盖一层「处理中」；编号变了闪一下；下一个空位显示加号。
- 时长用加减按钮；「电脑里的图」按钮直接从电脑里选图。
- 输入框：按 @ 弹出小窗（槽位里的图、资产库里几张、「在资产库里找…」）；引用的图不在槽位里时，发送会让那一处闪红并说明是第几处。

### 弹层

- 资产库：左边导入的文件夹带张数，右边图片网格；多选时标出点选顺序，已经在槽位里的标「在 N 号」；底部「已选 N 张，按点选顺序放进 N 号往后，槽位还剩 N 个」；读不了的文件夹显示原因和重试；导入文件夹弹窗能手填路径，也能点「选择…」弹系统窗口；按文件名搜时每张图下面写它在哪个文件夹。
- 上传清单：顶部「复制提示词」，底部「复制全部路径」，每行写尺寸和文件大小。服务端：打开清单时补上文件大小。
- 拼图：左栏行数、列数、格子边长、编号开关、存到哪个文件夹（从资产库文件夹里选）、文件名；中间点格子选中，点右栏的图放进选中那格，格子上有清空按钮；「只保存」和「保存并放进槽位」。服务端：拼图接口接受文件名。
- 系统提示词原文：加「复制原文」。

### 设置

- 左边分区导航。
- 工作文件夹：显示「能读写」、里面有几个画布、几套系统提示词、几套模型配置；「换一个文件夹…」先确认再弹系统窗口；「在资源管理器里打开」。服务端：加检查能不能写入、在资源管理器里打开文件夹两个接口。
- 模型配置：左边列表（密钥配没配、价格摘要），右边表单，改了自动保存，没有保存按钮；密钥只能录入，存好就清空、只显示「已配置」；测试连接显示耗时；一个链接「填本地假模型的地址」。
- 系统提示词：列表显示字数、自带还是自己建的、哪套是新节点默认；新建时复制当前选中的那套；改了自动保存。

## 现在有、原型里没画的（保留）

- 从 Windows 资源管理器直接把图拖到槽位区。
- 节点卡片右键菜单，内容和「…」菜单一样。
- 资产库多级子文件夹（原型只画了一层，更深的往里缩进）。
- 资产库手动重新扫描，放进文件夹的「…」菜单。

## 影响和冲突

- **手机和平板连不上。** 原型做了手机布局，但服务只监听本机 127.0.0.1（开发计划里定的安全要求），别的设备打不开。样式照搬，手机布局留着，不专门测。
- **资产库从常驻左栏变成弹窗。** 以前的「双击图进槽位」「从左栏把图拖进槽位或拼图格子」没有了，换成「点选后放进槽位」和拼图弹窗自带的选图栏。这是设计的决定，照做。
- **端到端用例要改写。** 20 条用例测的内容不变，但几乎都要换成新界面的点法。

## 分步

在新分支上做，每一步单独能回退：

1. 公共部分（两份样式、图标、主题切换、提示条、菜单、确认框）、首次设置页、设置页。
2. 首页。
3. 画布工作台：节点图、工具条、缩放条、节点卡片和菜单、撤销重做。
4. 对话面板：头部、消息、提示词框、底部的槽位和输入框。
5. 弹层：资产库、上传清单、拼图、系统提示词原文。
6. 收尾：端到端用例全部改完重跑，和原型逐屏截图对比（1440×900，暗色和亮色）。

第 1 步做完以后，还没搬的页面会被新样式带歪一点，到第 5 步全部搬完才完整，所以放在分支上做，main 一直是能用的。

每步做完：跑类型检查和测试，截图和原型对比，停下来给你看，你说下一步再继续。
