建议用 ComfyUI 自带接口，原因是少依赖一层：面板是第三方镜像自带的，代码做了混淆，镜像更新时行为可能变；ComfyUI 自带接口是标准做法，资料多。代价是上传、轮询、下载这几步要我们自己写。

ComfyUI 自带接口怎么调

  1. 在 ComfyUI 网页里打开工作流，用菜单里的「导出（API）」得到 API 格式的 JSON，存进我们系统。
  2. 上传底图：POST /upload/image（表单字段 image），返回服务器上的文件名。
  3. 把文件名填进「加载图像」节点，再改提示词、种子等。以 E05 为例：节点 4 的 image、节点 6 的 text、节点 8 的 seed。
  4. 提交：POST /prompt，请求体 {"prompt": 工作流JSON}，返回 prompt_id。
  5. 等完成：轮询 GET /history/{prompt_id}，或者连 /ws?clientId=… 收实时进度。
  6. 下载：从任务记录的 outputs 里拿到文件名和子目录，GET /view?filename=…&subfolder=…&type=output。

关机前从本机调过 /system_stats、/prompt、/object_info/LoadImage，都正常返回。

遮罩怎么传

  • 「加载图像」节点从图片的透明通道读遮罩：图里透明的地方，就是要重绘的地方。ComfyUI 遮罩编辑器保存的也是这种图。
  • 接入时在我们自己的画布里涂遮罩，把涂过的地方做成透明，存成 PNG 上传就行，E05 不用改。
  • E05 的测试就是用这种图跑的，重绘的位置和透明区域一致。
  • 不需要切新版节点界面。ComfyUI 自带的 Painter 画板节点虽然能在网页里直接涂，但它的遮罩只能在网页上画，接口调用用不上。

安全

现在的情况

  • 两个公网地址都不需要账号或密钥。拿到面板地址就能提交任务、启停 ComfyUI、清空输出；拿到 ComfyUI 地址就能提交任务，插件管理器（ComfyUI-Manager V3.42，安全级别 normal）的接口也对外开着。
  • 地址里有一串随机字符，别人猜不到，但地址一旦被看到（截图、聊天记录、共享的配置文件），对方就能用。

SSH 公钥为什么拦不住

  • 公钥只管 SSH 登录。两个 8443 地址是 AutoDL 自己做的端口转发，不经过 SSH。
  • AutoDL 文档说明每台实例的 6006、6008 端口都会映射一个公网地址，文档里没有关闭或加密码的选项。
  • ComfyUI 虽然只监听机器本机（127.0.0.1），公网地址照样能访问，这一点调过接口确认了。所以「只监听本机」也挡不住。

想做到「有私钥才能用」

只能让 ComfyUI 和面板都不占 6006、6008，你和我们系统都改走 SSH 隧道访问，比如 ComfyUI 改到 8188 端口后：

ssh -N -L 16006:127.0.0.1:8188 autodl-4080

然后访问本机的 http://127.0.0.1:16006。代价：

  • 端口写死在镜像的启动脚本里：/root/zealman-app/start-comfyui.sh 第 164 行 PORT=6006，面板自带的画布服务（start-services.sh 第 184 行）也按 6006 去连。改了以后面板的部分功能可能失效。
  • 镜像更新时可能又被改回去。
  • 另一台机器也要放一份私钥，用之前要先把隧道开着。

建议先不动，把地址当密钥对待：接入时跟模型密钥一样只存在本机配置（%APPDATA%\media-agent\config.json），不放进两台机器共用的工作文件夹，也不发到群里。

E05 局部重绘修复

详细说明见同目录的 e05-inpaint-fix.md。要点：

  • 涂遮罩的功能原版就有，在「加载图像」节点的右键菜单里（Open in MaskEditor），但写用法的分组标题被截断了，看不到。当天跑的两次都没涂遮罩，所以图没变。现在节点标题和旁边的说明节点都写了怎么涂。
  • 原版把涂过的地方填成灰色再画，这只适合专门的重绘模型；现在换成普通模型也能用的方式。
  • 原版把整张 2832×2048 的大图送进模型，现在只裁出遮罩附近一块，按 1024×1024 重绘，再拼回原图。
  • 原版遮罩外的画面也会被改，现在遮罩周围一圈以外保持原图像素。
