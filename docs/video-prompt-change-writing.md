# 视频提示词「写变化」手册

配套调研：`docs/research-video-prompt-change.md`。这份是可直接抄用的部分：规则、词库、改写对照表、自检清单。

写给 MiniMax H3 的中文提示词，但对任何视频模型都成立。核心只有一句：**每一句话都要能回答「从什么变成什么」。**

---

## 一、一条主规则

画面里没有变化，模型就没有东西可演。所以：

- 描述**状态**的字句（她穿深色西装、房间是冷调）只占开头一小段，用来锚住身份和场景。
- 剩下的篇幅全部用来写**变化**：什么动了、怎么动的、动到什么程度、动完停在什么状态。
- 判断一句话该不该写：把它读一遍，问「这句话里有变化吗」。没有变化的内容，要么删掉，要么补上变化。

四个槽位，每个角色、每个镜头都套一遍：

| 槽位 | 写什么 | 例子 |
| --- | --- | --- |
| 起态 | 此刻画面上看得见的具体状态 | 她双手垂在身侧，指节松开，呼吸平稳 |
| 触发 | 什么让它开始变（外部事件或内部冲动） | 门在她身后响了一声 |
| 过程 | 怎么变：哪个部位先动、方向、幅度、速度、先后顺序 | 肩膀先绷紧，半秒后头才转过去，下颌收了一下 |
| 落态＋泄露 | 稳定成什么状态；有没有压不住的细节 | 她定住不动，只有指尖在轻轻发抖，喉咙滚了一下 |

「泄露」是最好用的一格：情绪被压住的时候，身体会漏出来。写一个压不住的小动作，比写十个形容词都有效。

## 二、五种空话，和它们的替代物

| 空话类型 | 例子 | 为什么没用 | 换成什么 |
| --- | --- | --- | --- |
| 情绪词 | 她很高兴、他很悲伤 | 模型只收到一个标签，只能给通用表情 | 面部肌肉＋身体＋呼吸＋声音，见第四节 |
| 评价词 | 画面很美、令人感动、很震撼 | 不是画面内容，模型无法执行 | 删掉，换成看得见的细节 |
| 抽象比喻 | 像断线的风筝、心如死灰 | 需要意会，模型只能随机落地 | 换成物理动作：手松开、东西掉下去、她往后退了半步 |
| 意图/心理 | 她想离开、他在犹豫 | 看不见 | 动作序列：她看了一眼门，手撑住桌面，椅子向后刮出一声 |
| 氛围词 | 气氛紧张、很温馨 | 空 | 具体证据：两人之间隔了一整张桌子、谁先移开视线、杯子放下时没有声音 |

正例（都是"看得见或听得见"的）：手指、下颌、呼吸、视线、步态、衣料、光、影子、水面、灰尘、声音。

## 三、表情：不是标签，是过程

「高兴」不是描述，是一个结论。要写的是得出结论的过程。

三段时间线（起—转—落）：

```
起：脸上还是原来那个表情（写清基线）
转：哪个部位先动、动多少、多久
落：稳定成什么，剩下什么压不住的细节
```

六路拆解（从里面挑 2–4 路就够，别一次全写——通道堆多了模型顾此失彼，反而糊成一团）：

| 部位 | 可写的具体变化 |
| --- | --- |
| 眼睛 | 睁大／眯起、瞳孔收缩或放大、看向哪里、眨眼变快或停住、下眼睑绷起、眼角湿、眼白发红、视线躲开又转回来 |
| 眉毛 | 眉心上抬、眉头压低、眉毛内端上提（眉心挤出竖纹）、眉毛先动（比嘴早半秒） |
| 嘴 | 嘴角单侧／双侧上扬、嘴角向下压、嘴唇抿成一条线、下唇前推、嘴唇微张、咬住下唇、牙齿轻咬、笑容僵住后收起 |
| 下颌与颈 | 咬肌鼓起、下颌绷紧、下巴抬起或压下、喉结滚动、吞咽一下 |
| 呼吸 | 屏住、抽一口气、长吐、呼吸变浅变快、鼻翼张开 |
| 皮肤与其它 | 脸涨红、血色退去变白、鼻尖和耳尖发红、额头冷汗、眼线晕开、泪水在眼角积住没掉下来、鼻头红了 |

配合声音（H3 会一起出声）：吸气声、鼻音、气声、笑声、吞咽声、喉咙里的一声。

**别把表情当情绪仪表盘。** 「皱眉＝愤怒」这种一对一映射在学术上有实质争议，写死了反而容易得到一张通用脸。正确做法是**多通道叠加**（脸上 ＋ 呼吸 ＋ 手 ＋ 重心 ＋ 视线 ＋ 声音），让模型从多余的线索里自己推断——它推不出来才怪，线索不够才会给通用表情。

**最好用的是「反向组合」：脸上在压，身体在漏。** 面部保持平（抿唇、唇线拉直、眉头不动），同时让呼吸和声音漏出来（气息发抖、尾音发虚、喉结滚动、指尖抠住掌心）。这种写法最不容易糊成"通用夸张表演"，也是隐忍戏、克制戏的核心写法。反过来，"脸上大动 ＋ 身体也大动"通常只会得到一张卡通脸。

**时间量级**（有实证的说法）：宏观表情约 0.5–4 秒，微表情不到半秒。所以微表情要写"一闪"（眉心跳一下、瞳孔缩一下，半秒内回到原位），情绪转折要按秒写（2–4 秒）。提示词至少要给「起—峰—落」三个时点，只给一个峰值，模型就会全程保持峰值——看起来就是一张静止的脸。按肌肉逐条写（AU）是可选的高级做法，中文对照表在 `docs/research-emotion-to-visible-action.md`。

写表情的三条准则（社区共识，和上面三段时间线是一回事）：**不对称**（一侧先动，别左右同时到位）、**渐进**（从 A 过渡到 B，写出用了几秒，别瞬间切换）、**联动**（眼神、嘴角、下颌、呼吸依次接力，不要只动一块）。常见失败是四种：完美对称的表情、情绪瞬间切换、夸张卡通式、面瘫式静止。

兜底句（实在不知道怎么写表情时，直接用这句，比写"很高兴"强）：`表情自然克制，不张大嘴，不做夸张皱眉，不要卡通式表情。`

**别写过头**（海螺官方知识库的说法，也是实测经验）：一次转换只挑 2–4 个通道（脸上 2–3 个标记就够），把额肌、皱眉肌、鼻肌逐条列出来反而会让脸变形、出噪点。要转换就用「逐渐」「慢慢」这类连接词，别用「同时」「立刻」——写着"又哭又笑"模型会给一张两不像的混合脸，而不是先哭后笑。转换写太快会像跳帧，需要时明确写"缓慢"。

**"慢"不等于"慢动作"**：写「缓慢行走」模型容易理解成慢镜头。想要从容的走法，写步幅和节奏：「步幅很小，节奏不紧不慢，脚跟先落地再过渡到脚尖」，而不是「慢慢地走」。

写变化的三个加成技巧：

1. **写顺序**：脸先白、然后才笑；手先攥紧、然后才开口。顺序本身就是表演。
2. **写相反**：嘴上说没事，同时把杯子握得更紧。矛盾比一致更像真人。
3. **写截断**：情绪写到一半被打断（她刚要笑，被门外的一声压回去）。截断比完成更有戏。

## 四、情绪 → 可见变化（词库）

每条都是能拍到的。括号里是可用在 H3 提示词里的短句，直接抄。

**高兴／兴奋**：眼睛眯成一点、下眼睑鼓起（卧蚕出来）、嘴角先单侧上扬再带动另一侧、肩膀放松下沉、呼吸变深、笑声从鼻腔出来（眼睛先弯，然后嘴角才跟上；笑到一半收住又忍不住再笑）。

**悲伤**：视线落在地面或某个固定的点、眨眼变慢、上眼睑下垂、嘴角向下压、眉心挤出竖纹、喉结滚动一下（下眼睑先泛红、泪在眼角积住没掉下来、吸气时鼻子轻轻抽一下）。

**愤怒**：下颌绷紧、咬肌鼓起、眉头压低、鼻翼张开、眼球上移、颈侧青筋浮起、呼吸变粗（说话前先深吸一口气、语速变慢、声音压低、指节因为握拳发白）。

**恐惧／紧张**：瞳孔收缩、眼睛睁大露出眼白、上唇微微抬起、呼吸变浅变快、身体重心后移、手抓最近的支撑物（眼睛定住不动、然后飞快扫向声音来源、耳后和颈侧出汗）。

**惊讶**：眉毛先跳起来、眼睛睁大、嘴在吸气时张开、上半身微微后仰、手上的东西停住（前 0.3 秒完全静止，随后才做出反应，静止那段最关键）。

**厌恶**：鼻梁皱起、上唇抬起露出上牙、下巴后缩、头微微偏向一侧、视线躲开（看过一眼后立刻移开，然后皱眉再看回去）。

**隐忍／克制**（最出戏）：脸上几乎没有变化，只有下颌在动、喉结滚动、太阳穴跳、指尖抠住掌心、呼吸隔两秒才吐出来（眼睛先红，但表情维持不动，最后闭一下眼再睁开）。

**疲惫**：上眼睑下垂、眼睛缓慢眨、视线失焦、肩膀塌下来、脖子前倾、说话时气不够用（坐下时整个人往下沉一寸、站起来前先深吸一口气）。

**爱意／温柔**：视线停在对方脸上不移开、眼睛眯起来、嘴角轻轻上扬但不对称、头微微偏、呼吸放慢、说话声音变轻（手抬起来又放下，最后落在对方肩上）。

**轻蔑**：单侧嘴角上扬（一侧先动）、鼻息短促地哼出一声、眼睛半闭、下巴微抬、视线从下往上扫（笑不达眼底——眼睛没有跟着收敛）。

**尴尬**：视线乱扫、手不知道该放哪里、摸后颈或整理衣角、笑一下马上收住、耳尖发红、说话抢在别人前面又停住（先干笑半声，然后低头抿嘴）。

**释然**：屏住的那口气长吐出来、肩膀落下去、眉头松开、闭眼再睁开、手松开（原本撑着桌子的手离开桌面、身体向后靠回椅背）。

**决意**：呼吸吸满、下颌收住、视线定住不再移动、手停下所有小动作、身体从放松变成微微前倾（做决定前有半秒静止）。

**被击中／愣住**：所有动作在同一瞬间停下、瞳孔一缩、呼吸断掉一拍、手上的东西滑落、身体僵住（然后是那个"回过神"的小动作：眨一下眼、动一下手指）。

**过渡情绪**（最容易被跳过、也最值钱）：从笑到不笑、从愤怒到无力、从平静到崩溃。都要写"在哪一秒开始变、先变哪里"。例如：「她的笑维持了两秒，然后嘴角一点点落下去，眼睛还弯着，直到眼神也暗下来。」

## 五、不只是脸：全身与手

表情只占一半。身体的证据通常更便宜、更有效：

- **手**：攥紧、松开、指节发白、指尖发抖、拇指搓食指、抓住衣角、把手插进口袋、手抬到一半停住、手掌在裤子上擦一下。
- **肩颈**：肩膀耸起贴近耳朵、后来塌下去；脖子前倾；头低下去又抬起来。
- **重心与步态**：后退半步、往前挪半步、脚跟先着地还是脚尖先着地、走路速度变快或变慢、停下时身体还在往前晃。
- **视线**：定住、躲闪、扫视、追视、越过镜头看一眼再收回来、盯着一个点不移开（视线是观众读情绪的第一入口，几乎每个情绪段落都该有一句）。
- **小动作**：吞咽、舔唇、搓手、摸后颈、整理袖口、抱臂、后退、摸口袋、把杯子挪开两厘米。
- **构图上的变化**：她往画面边缘退了半步、她占画面的比例从半身变成只露肩（身体的位移比表情更能说明关系变化）。

## 六、画面里的其它东西也要变

一个镜头里只有人物在动，画面会显得"演"。同一句话里的环境、光、物体，都要有各自的变化：

- **光**：灯亮起或暗掉、车灯从画面外扫过、云把太阳遮住、光斑在墙上移动、屏幕的光映在脸上变化、逆光里头发边缘的轮廓光变强。
- **影子**：影子先到、人后到；影子沿墙面往上爬；影子盖住脸（比人物本体先进入画面更有压迫感）。
- **材质与物理**：鞋跟砸在湿地上溅起水花、掌心擦过地面、衣料被风掀起、头发被气流带起、水面倒影被打碎、灰尘在光束里翻动、蒸汽从切口涌出。
- **物体状态机**（官方示例的写法）：门关闭 → 手接近把手 → 手掌握住 → 铰链方向旋转 → 门完全打开 → 手松开。复杂动作拆成这六步，比"自然地打开门"稳得多。
- **别人的反应**：A 说话时 B 在做什么（摇头、移开视线、手指敲桌）。反应镜头是叙事成本的杠杆。

## 七、镜头也在变

画面在变、镜头不动是一类；画面不动、镜头在动是另一类。**一个镜头里至少要有一个在变**，两个都静止就是一张图。

- 运镜写成句子：类型 ＋ 幅度 ＋ 速度。例：镜头小幅慢速推进，对准她手里折起的信。中等幅度和常速不用写。
- **一个镜头只留一个运镜 ＋ 一个主体动作**（Sora 2 官方指南的原话就是这条）。想加第二个运动，就是该切镜或者该缩短镜头的信号。
- **焦段写数值比写形容词稳**：`85mm`、`24mm` 比"长焦""广角"更可控。
- **每镜最多两个轴**（社区经验值，不是模型硬限制）：推＋摇可以，推＋摇＋滚通常失控；特写配大幅环绕最容易崩脸。
- 甩镜（whip pan）有分歧：英文从业者明确说不可靠，中文案例集里有成片。要用就单独试一条，别和别的复杂运动叠在一起。
- 变的是构图不是机位：切镜要带来新信息（新主体、新空间、新状态、新视角、新时间），只是靠近一点就用运镜。
- 镜头可以"反应"：她摔倒，镜头跟着快速下降；她后退，镜头跟着退。镜头跟着主体走，比镜头自己走更像摄影。
- 光的三种写法：光源在哪、光怎么变、光照出了什么（反光、影子、轮廓光）。
- 某个镜头反复不对时，按这个顺序退：**固定镜头 → 简化动作 → 清空背景**，然后再一项一项加回来（Sora 和 Runway 官方都给了这个兜底）。

## 八、时间预算（经验值）

H3 一次 4–15 秒。下面这张表是**写作用来估数的经验值，不是换算表**：同一段 10 秒的提示词，实测里即梦能跑完四拍动作，可灵只跑完一半（澎湃/AIX 财经的三模型实测）。换模型、换画幅、换素材都要重新试。表格只用来判断"这段时长塞得下几件事"。

| 变化 | 大致需要 |
| --- | --- |
| 一个微表情（挑眉、瞳孔收） | 0.3–1 秒 |
| 一个小动作（抬手、转头） | 1–2 秒 |
| 一个完整动作链（起身走到门口） | 3–5 秒 |
| 一句短台词 | 英文按每秒约 2.5 个词算，中文按每秒 4–5 个字算，末尾再留约 1 秒让嘴闭合、情绪落定 |
| 情绪从 A 转到 B | 2–4 秒（少于 2 秒会像跳帧） |

由此得到的分配习惯：

- **切成 2–3 秒一格**，每格只放**一个主状态变化**，最多再加一个跟着它的联动细节（社区三份独立来源收敛到的写法）。同一件事的微动作可以留在同一格里。
- 一个镜头只给一个主要动作目标，次动作服务于它。
- 2–3 个镜头在 15 秒里最稳；4 个以上容易身份漂移、空间断裂。
- 台词长度和镜头长度对齐，宁拆段不要加速念。
- 最后一段留出收敛时间（首尾帧、尾帧任务尤其），最后 1–2 秒别再加新信息。
- H3 的帧数只能取 17 的倍数加 5，实际时长是对齐过格子的（5.167／8.000／10.125／12.250／15.083 秒，只有 8.000 整）。切镜时间和"说到最后一句"都要按这个格子留余量，别把落点正好压在末尾。见 `docs/research-h3-long-video.md`。

## 九、改写对照表（空话 → 具体）

左边是常见写法，右边是能直接进提示词的版本。

| 空话 | 具体的 |
| --- | --- |
| 她很高兴 | 她先是嘴角单侧上扬，随即眼睛也弯起来，肩膀松下去，笑声从鼻腔里出来 |
| 她很悲伤 | 她的视线落在地面上不动，眨眼变慢，下眼睑泛红，泪在眼角积住没有掉下来 |
| 她很生气 | 她下颌绷紧、咬肌鼓起，鼻翼张开，深吸一口气后才开口，声音压得很低 |
| 她很紧张 | 她的手指在裤缝上搓了两下，喉咙滚了一下，呼吸又浅又快，重心向后移了半步 |
| 她很惊讶 | 她的眉毛先跳起来，眼睛睁大，吸气时嘴张开，上半身微微后仰，手里的杯子停在半空 |

## 十、输出前自检（12 条）

1. 每句话都能回答「从什么变成什么」吗？纯状态句超过开头一小段就该删。
2. 每个情绪词都至少配了两个可见证据吗（一个在脸上、一个在身上或呼吸上）？
3. 给了「起—峰—落」三个时点吗？还是只给了一个峰值（只给峰值＝一张静止的脸）？
4. 通道数在 2–4 之间吗（不是把每条肌肉都写一遍，也不是只写一个部位）？
5. 写顺序了吗（谁先动、隔多久）？
6. 写泄露了吗（压不住的小动作）？
7. 写视线了吗（看向哪、什么时候移开）？
8. 画面里除人物外，光和物体有自己的变化吗？
9. 一个镜头里是不是只有一个主要动作目标、一个主运镜？
10. 每个切镜都带来了新信息吗（新主体／空间／状态／视角／时间）？
11. 变化总量塞得进这段时长吗（按第八节的经验值估一遍）？
12. 有没有漏在里面的空话（情绪词、评价词、比喻、意图词、氛围词）？

## 十一、别写这些

- 情绪结论：很高兴、很悲伤、很愤怒、表情复杂、充满感情。
- 评价与感叹：画面很美、令人震撼、非常感人、大片感。
- 抽象比喻：如同断线的风筝、心如死灰、时间凝固了。
- 心理与意图：她想离开、他在犹豫、她意识到自己被跟踪了（除非同时写了外部动作）。
- 氛围标签：气氛紧张、很温馨、很压抑。
- 一个镜头塞多个动作目标：一边跑一边打电话一边回头看爆炸。
- 冲突运镜：同一时间既固定又跟拍、一秒里又推又拉又环绕。
- 只堆风格词不写内容：电影感、高级感、唯美、8K。
- 「自然」「放松」「从容」这类词：模型不知道什么叫自然，译成身体细节——「重心压在一条腿上」「脊柱有一点弧度」「步幅小、不紧不慢」。
- 生成参数：分辨率、帧率、运动强度写进提示词没用还干扰，交给设置项（字节官方明确说没用且干扰；`4K`／`8K` 这类风格化画质词有分歧，见调研报告）。
- 一长串通用负面词：负面词只写你此刻正看着的那一个毛病（比如"缆线重复""标签变形"），两三个封顶。运动类的崩坏（多指、漂移、闪烁）负面词基本治不了，要往上游改：缩短镜头、一次只留一个不稳定元素、锁参考图或 seed。
- **指望负面提示词之前先看 cfg**：负分支的公式是 `out = uncond + cfg × (cond − uncond)`，**cfg=1 时负面词在数学上恒等于无效**（采样器会直接跳过负分支）。本地工作流里大量模板是 cfg=1，负面框里还预填着词，改了等于没改。走少步蒸馏的模型，负面提示词的空间本来就被压缩了。H3 本身没有独立的负面提示词字段，不想要的就在正文里写清"画面里要有什么"。

## 十二、从图片标签转成视频变化

素材库里那套 danbooru 中文标签（`data/danbooru/zh/general.csv`）是**图片**用的：一个标签对应一帧上的静止特征。视频提示词要的是几帧之间的变化，所以标签只能当起点，不能直接搬。转法：

| 标签（含义） | 直接搬进视频会变成 | 写成变化 |
| --- | --- | --- |
| smile（嘴角上扬） | 全程挂着同一个笑 | 嘴角先单侧扬起，眼睛随后弯起来，维持两秒，笑一点点落回去 |
| blush（脸颊红晕） | 一开场脸就是红的 | 血色先从耳尖起来，两秒里漫到颧骨，她低头把它藏起来 |
| wide-eyed（瞪眼露眼白） | 全程瞪着眼 | 瞳孔先收缩，眼白露出来，呼吸断了一拍，随后眨了一下眼 |
| trembling（发抖） | 整个人一直在抖 | 指尖开始抖，幅度一点点变大，她把手插进口袋按住 |
| gulping（喉咙鼓动） | 喉咙一直在动 | 喉结滚动一下，带一声吞咽，之后他开口说话 |
| forced_smile（苦笑） | 一直笑 | 嘴角抬起来但眼睛没有跟着弯，维持一秒就落回原样 |
| looking_away（移开视线） | 一直不看人 | 视线从对方脸上滑到桌面，停了半秒，又抬回对方眼睛 |
| leaning_forward（前倾） | 一直保持前倾 | 上身缓慢前倾，到一半停住，两秒后才补上剩下那一半 |
| heavy_breathing（粗重呼吸） | 从头喘到尾 | 呼吸从平稳变粗，肩膀跟着起伏，最后一口气长吐出来 |
| glaring（怒视） | 全程怒视 | 眼睛先眯起来，视线钉住对方不动，下颌同时绷紧 |
| looking_down（低头） | 一直低着头 | 头一点点低下去，下巴几乎贴到锁骨，然后抬眼看了一下 |
| clenched_teeth（咬牙） | 一直咬着牙 | 咬肌鼓起，牙关咬住，说到一半才松开 |

一句话：**标签是名词，视频要的是动词。** 见到标签就问「它从什么状态变到这个状态、中间花了多久、变完又怎样」。
