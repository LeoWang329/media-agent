这一版改了什么

上一版把「做什么」塞在编辑栏最下面，四个功能的字段又挤成一长条，看着就是一股脑堆在一起。这一版改成先选功能，面板只留这个功能要的东西：

  1. 「功能」下拉提到第一行——点开编辑节点，第一个看到的就是「要干什么」。
  2. 多了一个「提示词」下拉——每个功能配一套现成的提示词，选一条就填进去，也能自己写。
  3. 字段跟着功能走——转真人没有「相似度」，局部重绘才有「重绘强度」；转真人的提示词是锁死的，消息区干脆换成说明卡，不让模型瞎写。
  4. 「模型提示词」也有一套、跟着功能切——消息区最上面那行。指令编辑 / 换装 / 局部重绘 / 转真人各一份，选了哪个功能就用哪份；想改原文去设置页。

一条竖线，从上往下就是流程

  1. 功能：指令编辑 / 转真人 / 换装 / 局部重绘（这一轮把这四个做完，再补放大·高清、四视图、扩图、深度迁移）
  2. 模型提示词：跟着功能自动切的那一份（四份在 docs/prompts/edit*.md）
  3. 图：节点里可以放好几张，但每次只用选中的那一张（点谁选谁，单选）
  4. 提示词：选一条现成的，紧跟着那行就是这次真正发出去的话，可以直接改
  5. 这个功能自己的字段：相似度 / 谁写词 + 辅助词 + 人物 LoRA / 掩码 / 重绘强度（转真人没有相似度，局部重绘才有强度）
  6. 开始

试试点这些

  • 点 功能 那个框 → 四条功能，每条一句说明；选一条，下面整块跟着换
  • 点 提示词 那个框 → 换衣服 / 换背景 / 加个东西 / 去掉个东西 / 改光线 / 改表情，选一条看下面那行被填成什么
  • 切到 转真人 → 上面那堆候选框换成说明卡；提示词那行不给下拉，改成 谁写词：让模型看图写 / 我自己写 —— 切「我自己写」会冒出辅助词词条，点一下接进提示词
  • 切到 局部重绘 → 多一个「在图上拖框或涂抹」，点它去 掩码编辑器
