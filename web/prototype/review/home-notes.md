# 首页原型说明

## 怎么看

- 双击 `web/prototype/home.html` 就能开，不用联网。
- 右下角虚线框「原型」是切状态用的，正式程序里没有。能切的状态：
  - 正常：有正在生成的节点、有回复失败的节点、有一套模型配置没填密钥
  - 正在读取工作文件夹
  - 工作文件夹打不开
  - 一个画布都没有
  - 有画布，还没有节点发过消息
  - 还没打过星
  - 密钥都填了（顶部那条提示不出现）
  - 画布有几十个
  - 按名字找，没找到
  - 刚删了一个画布（底部提示里能撤销）
- 截图在 `review/` 下：`home-1600-dark.jpg`、`home-1366-light.jpg`、`home-390-dark*.jpg`，还有打不开文件夹、还没发过消息、正在读取这三个状态的截图。

## 布局为什么这样排

- 最常做的事是「接着改上次那个节点」，所以左上角最大的一块给了最近动过的节点，一屏里能看到 8 个，不用滚。1366×768 的浏览器里，8 个卡片底边在 636 像素，刚好能完整显示。
- 打星的提示词放在右边一栏，滚动时一直留在屏幕上。复制提示词、复制译文、打开上传清单都直接在这一栏里点，不用先进画布。
- 全部画布排在最近节点下面。这块用得最少，但数量会越来越多，放在下面，画布再多也不会把上面两块挤下去。
- 「这台机器上要处理的事」只在有问题时出现，一条一行，放在最上面，按钮直接去设置里对应的位置。里面只写「还没填密钥」，不显示任何密钥字符。
- 窄于 1080 像素时改成一栏，顺序是：最近节点、打星、全部画布。窄于 720 像素时，节点卡的画布名单独占一行，画布卡两列。

## 这次看截图时顺手改的

- 节点卡左边的缩略图：图片张数排不满格子时，最后一张横着占满，不留空格。
- 原型切换框原来在左下角，会压住节点卡，挪到了右下角。
- 手机上节点卡底部那行把画布名挤成「新年广…」，改成画布名单独一行；顶部提示条的按钮换到文字下面。
- 手机上画布卡的「8 个节点」和「2 个打过星」折行时，行首会多出一个「·」，去掉了。
- 工作文件夹打不开或者正在读取的时候，「新建画布」按钮不能点，因为新画布也写不进去。
- 「还没发过消息」状态里画布封面原来有图，但封面取的是最近放进槽位的图，没发过消息就不该有，改成了空封面。

## 原型里的假数据和限制

- 「新年广告片」的节点、提示词、译文都来自画布页现有的样例数据。另外两个画布各编了一个节点（萨摩耶「推门进店·慢动作」、腕表「侧光转台·表盘特写」），为的是让最近节点里能看到跨画布的效果。
- 除了「新年广告片」，点其他画布或者其他画布里的节点，只会弹一句「原型里只做了「新年广告片」这张画布的内容」。
- 「几十个画布」状态里多出来的画布名和封面是编的。
- `home.html` 引用了 `canvas.css`，因为提示词里标记的颜色和上传清单的样式都写在那里面。

## 建议加的功能（没画进页面）

1. 最近节点卡上直接显示「正在生成」的进度秒数，生成完不刷新页面也能变成完成状态。
2. 打星的提示词按画布筛选。打星多了以后，只看当前项目的会更快。
3. 画布可以置顶。长期在做的项目不会被新画布挤到后面。
4. 回收站入口：在全部画布标题旁边放一个「回收站」，撤销提示关掉以后还能把画布找回来。
5. 首页快捷键：`N` 新建画布，`/` 聚焦到按名字找画布。
6. 最近节点卡上加「复制最新提示词」，不进画布也能拿走最新一版。
