# 提示词画布

本机跑的一个网页，用来写 MiniMax H3 的视频提示词：左边是资产库（你本机的图片文件夹），中间是画布（每个节点是一段和 agent 的对话，可以从任意一条消息 fork 出新节点比较不同写法），右边是对话面板（上面有 9 个图片槽位、视频时长和画面比例）。图片在提示词里用 `<Picture 1>` 到 `<Picture 9>` 引用。第一版只出提示词，不生成视频。

需求是怎么定的看 [docs/requirements-interview.md](docs/requirements-interview.md)，具体怎么做看 [docs/dev-plan.md](docs/dev-plan.md)。

## 安装

需要 Node 24（`node -v` 看一下）。

```bash
npm install
```

## 运行

```bash
npm start
```

打包前端、起服务、自动打开 http://127.0.0.1:3711 。服务只监听本机，同一个局域网里的别人连不上。

开发时用 `npm run dev`：服务在 3711、前端在 http://localhost:5173 、假的大模型在 3799，改代码自动生效。

## 第一次打开

会直接跳到设置页，按顺序设两样：

1. **工作文件夹**：选一个空文件夹，建议放在同步盘里（两台机器共用）。设好后里面会出现 `prompts/` 等目录，带三套自带的系统提示词。
2. **模型配置**：填名字、接口地址（OpenAI 兼容的 `/v1`）、API 密钥、模型名、发图长边（默认 1600，发给模型的图按这个长边缩）。点「测试连接」确认能通。想看每条回复花了多少钱，再填价格：选币种，按每百万 tokens 填输入价、输出价和缓存命中价（留空就不算钱）。

想先空跑不花钱：另开一个终端 `npm run mock-llm`，接口地址填 `http://127.0.0.1:3799/v1`，模型名填 `mock-model`，密钥随便填。这个假模型只会把收到的东西复述回来。

## 怎么用

1. 首页「新建画布」→ 进去点「新建节点」。
2. 放参考图：左栏「导入文件夹」选一个放图的文件夹，双击图片进槽位；也可以直接从 Windows 文件夹里选几张拖到槽位区。点某个槽位会弹出选图窗口，选中的图就放进那一格。
3. 面板顶上选这个节点用哪套系统提示词：`ref2va`（图提供人物、场景、风格或分镜，最多 9 张，新节点默认这套）、`i2v`（一张图当首帧往后演）、`t2v`（不用图）。设置页里可以改这三套、也可以新建自己的。
4. 槽位右边选视频时长（4 到 15 秒）和画面比例，然后在下面写需求发出去。换图、调顺序、改时长都不用重说，发下一句时程序会自动告诉 agent 哪里变了。
5. 话里要指某张图时，打一个 @，弹出选图窗口：上半部分是当前 9 个槽位，点一张就在输入框里插一个带缩略图的小标签；下半部分是资产库，选一张还没进槽位的，程序先把它放进下一个空槽位再插标签。发出去时标签变成 `<Picture 2>` 这样的编号，调了槽位顺序编号自动跟着变。
6. 回复里的提示词框可以：复制、翻译、打星（记住这版效果好）、手动改（生成一个新版本，不重新问模型，改的时候一样能用 @ 选图）、看上传清单（每张图该传哪个文件）、沿这个方向 fork 出新节点。
   - 翻译：选语言（英文、中文、日文、韩文），要求可写可不写，用这个节点选的模型问一次。部分名字、`<Picture 1>` 这类标记、台词和画面里的文字默认照原文留着，想一起翻就写在要求里。翻好的存下来，下次点「翻译」直接看，也可以改了要求重新翻。发给模型的翻译说明在 `docs/prompts/translate.md`。
7. 点有图的槽位，菜单里「放大看」能看大图，点图切换原始大小。
8. 对话长了，点面板顶上的目录按钮，左边浮出每一轮需求和回复的摘要，点一下跳到那一轮。
9. 想留着对比就 fork：从任意一条消息 fork 出新节点，改图或改说法，两边都留着。
10. 几张图想合成一张宫格图（只占一个槽位）：左栏点「拼图」，选行数列数（各 1 到 3）和格子边长，从左边把图拖进格子，格子之间拖动可以调顺序，「加编号」默认勾着（每格左上角加个数字，提示词里用「2 号格」指某一格，并提醒视频里不要出现这些数字；取消勾选的话提示词里用「左上」「第二排中间」指某一格）。保存时选个文件夹，拼好的图叫 `collage-日期-时间.jpg`。
11. 回复角落显示用的哪个模型、哪套提示词、花了多少 token；模型配置里填了价格就跟着显示这次花了多少钱，接口报了缓存命中的话那部分按缓存价算。面板顶上的「这个节点花了」连翻译花的也算上。
12. 画布上的操作按 Ctrl+Z 退回上一步，Ctrl+Shift+Z 再做一遍：拖动、折叠、删节点（连子节点一起回来）、改名、槽位和时长比例都算，最多 50 步；发出去的消息不在里面。换画布就重新开始记。
13. 回到首页：最上面是最近动过的节点，跨全部画布，点一下直接回到那段对话；右边是打过星的提示词，不进画布就能复制原文和译文、看上传清单；下面是全部画布，能按名字找。哪套模型配置在这台机器上还没填密钥，首页顶上会提示。

## 数据存在哪

**工作文件夹**（放同步盘，两台机器共用）：

```
model-configs.json          模型配置，不含密钥
prompts/<名字>.md            系统提示词
prompts/.history/           每次用到的提示词版本存一份
canvases/<画布 id>/          canvas.json、nodes/、images/（放进过槽位的图和发给模型的小图）、images.json
.trash/                     删掉的画布和节点先移到这里，不直接删
```

**本机配置**（Windows 是 `%APPDATA%\media-agent\`，其他系统是 `~/.media-agent/`）：

```
config.json                 工作文件夹路径、各模型配置的密钥、导入了哪些资产库文件夹
thumbs/                     资产库缩略图缓存，删了会重新生成
```

密钥和资产库文件夹只存在本机，不进同步盘。

图片一放进槽位就复制一份到画布文件夹里，之后原图被移走、删掉也不影响画布；超出 H3 要求（每边 256 到 5760 像素、每张 30 MB）的那份会自动处理到要求以内，上传清单里会告诉你该传哪一份。

## 换一台机器

1. 新机器装 Node 24，拷一份这个仓库，`npm install`。
2. 把工作文件夹放同步盘，新机器在设置页指到同一个目录。
3. 模型配置会跟着同步过来，**密钥要在新机器上再填一次**。
4. 资产库导入的文件夹是本机路径，新机器要重新导入。
5. 别两台机器同时开同一个画布，同步盘可能生成冲突副本。

## 测试

```bash
npm test          # 单元和服务端集成测试
npm run test:e2e  # 端到端，自己打包前端、在 3712 端口用临时目录起服务，不碰你的真实配置
npm run typecheck # 类型检查
```

端到端测试要用 Playwright 对应的 Chromium，本机没有的话先装一次：`npx playwright install chromium`。测试只对假模型跑，不会调用真模型、不花钱。

## 不对劲的时候

- **页面打不开**：看 3711 端口是不是被别的程序占了。
- **发消息报错**：设置页点「测试连接」，错误里带接口返回的原文。
- **图片放不进槽位**：只支持 jpg、jpeg、png、webp；heic、heif、gif 在资产库里会灰显「不支持」。
- **想从头来**：删掉本机配置目录 `%APPDATA%\media-agent\`，重开就是第一次的样子（画布都在工作文件夹里，不会丢）。
